# 涨跌停分析（limit-analysis）

拉取**涨停池 + 炸板池 + 跌停池**，算**涨停梯队 / 炸板率 / 封单额 / 题材归类**，输出短线情绪周期数据包。脚本只取数算聚合，「情绪周期 / 主线题材」结论由 AI 依据下方框架生成。

与其他 skill 的分工：
- `market-heat` = 全市场热度雷达（涨幅榜/跌幅榜/龙虎榜 → 热点/避坑方向），其涨停家数用 9.9% 近似；
- `dragon-pullback` = 单只龙头缩量回调二次启动（从涨停池筛候选，但只服务于龙回头策略）；
- **本 skill** = 涨跌停的**深度结构分析**（梯队/炸板/封单/题材），精确口径，是短线情绪的「温度计」。

## 用法

```bash
py .claude/skills/limit-analysis/scan_limit.py            # 最近交易日
py .claude/skills/limit-analysis/scan_limit.py 20260911   # 指定交易日
```

脚本输出 **6 段数据包**：

- **【1. 涨停梯队】**：涨停总数、首板/2板/3板/4板+ 分层、最高连板（空间板）、连板股明细（连板数/涨停统计/封单额/题材）
- **【1b. 连板梯队矩阵】**：近 8 日最高连板演变（同花顺 limit-up-ladder）+ 近 30 日连板次日晋级率（封板/断板）→ 情绪强/中/弱
- **【2. 炸板率】**：涨停数 + 炸板数 → 炸板率 + 情绪判定（封板坚决/中性/分歧加剧）
- **【3. 封单额 TOP】**：涨停池按封板资金降序（真金封板强度）
- **【4. 题材归类】**：涨停题材聚集 + 炸板题材聚集（按涨停原因/所属行业聚合计数）
- **【5. 跌停池】**：跌停股明细（涨跌幅/换手率；同花顺源无连续跌停/封单/行业）
- **【6. 情绪面汇总】**：涨停/跌停/炸板家数、炸板率、最高连板、跌停题材聚集

## 分析框架（AI 在数据包之上生成报告）

### 一、情绪周期（【1】+【2】+【6】）
- **连板高度**：最高连板（空间板）是情绪天花板。高度板持续晋级（3板/4板+增多）= 情绪上升期；高度板断板、高度下降 = 退潮期。
- **炸板率**：≤20% = 封板坚决、情绪强；20~35% = 中性；>35% = 分歧大、情绪弱。
- **涨停 vs 跌停**：涨停远多于跌停 = 进攻；跌停增多 = 恐慌/退潮。

### 二、主线题材（【4】涨停聚集 + 高度板所在行业）
- **涨停题材聚集 + 高度板题材** 指向同一方向 = 当前短线主线（如「算力题材聚集 + 空间板也是算力股」）。
- **首板多但无高度板** = 题材轮动快、一日游；有高度板带队 = 主线有持续性。
- 结论放句首：如「当前短线主线是 XX（涨停聚集 + 高度板共振）」。

### 三、退潮方向（【5】+ 跌停题材聚集）
- **跌停池 + 跌停题材聚集** = 资金正在出逃的方向，警惕退潮。连续跌停股尤其危险。

### 四、结论（一句话 + 操作提示）
先给**一句话结论**（短线情绪处于什么周期 + 主线题材是什么 + 该追还是该等），再给操作提示（情绪强→可参与主线龙头、情绪分歧→只做首板不追高、情绪退潮→空仓/防守）。

**免责声明**（每次必带）：以上基于公开涨跌停数据，不构成投资建议；短线情绪波动大，追高须设好止损、独立决策。

## 注意事项

- **数据源**：涨停池/炸板池/跌停池（同花顺官方金融数据，需 `.env` 配置 `HITHINK_FINANCE_API_KEY`；无 key 回退东财 `stock_zt_pool_em` 等，需 `pip install akshare`）；连板梯队矩阵（同花顺 `limit-up-ladder`，需 key，无 key 时跳过【1b】）。**不依赖 `MX_APIKEY`**。
- **本地库兜底**：涨停池在同花顺 + 东财均失败时，改用本地 marketdb 重建（未复权涨幅 + 涨跌停制度：主板 10% / 创业科创 20% / 北交所 30% / ST 5%），能给出「连板数」，但无封单额/题材，且炸板/跌停不可重建；数据截至本地库最大日期（可 `py tools/marketdb_local.py sync` 更新）。
- **精确口径**：涨跌停由同花顺/东财精确判定（主板 10%、创业板/科创板 20%、ST 5%），彻底替代 `market-heat` 的 9.9% 近似。
- **数据保留期**：同花顺源无保留期限制；akshare 涨停池只保留约 2 周，本 skill 只查当日/最近交易日，不受影响。
- **非交易时段**：显示最近交易日的收盘涨停数据（节假日顺延）。
- **题材归类口径**：同花顺源用「涨停原因」（按 `+` 拆分统计，更贴近题材）；东财源用「所属行业」近似。精确消息面叠加 `/news-search`。
- **不臆造**：脚本没查到的（具体涨停催化消息）不要编造，需要时叠加 `/news-search` 查题材催化、`/dragon-pullback` 查高度板是否构成龙回头。
