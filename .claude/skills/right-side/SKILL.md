# 右侧选股扫描（right-side）

对**指定板块/行业**做右侧机会扫描：在成分股里找出「**已站上关键均线、趋势转多、放量突破/创新高、量价齐升**」的票，顺势跟进。这是**右侧交易**——在底部右侧、反转已确认之后买入。

> ⚠️ **定位是「趋势确认的观察清单」，不是「选出来就买」**：脚本输出的是「已启动」候选，本身**不构成买入信号**。3 年 × 沪深300/中证500/中证1000 回测显示，右侧突破确认信号相对同频随机基线 **净 edge 仅 ±0.2%（≈ 无超额）**，本质是跟随大盘 beta；突破日买入≈买在短期高点附近（如万华化学在 ~78 选出后回落 ~70，-10%）。**真正的买点要等回踩不破位再介入**（见「四、买点与止损」），追在放量长阳顶是最差入场点。

与 `left-side`（左侧：超跌埋伏、赌反转）互为镜像。与 `dragon-pullback` 的关系：dragon-pullback 是「龙头连板后的缩量回调二次启动」的右侧特例；本 skill 是**不限龙头、任意板块的放量突破顺势**泛化版。

## 用法

```bash
py .claude/skills/right-side/scan_right_side.py <板块/行业> [输出数量]
```

示例：

```bash
py .claude/skills/right-side/scan_right_side.py 半导体
py .claude/skills/right-side/scan_right_side.py 创业板 20
py .claude/skills/right-side/scan_right_side.py 中证1000 15
py .claude/skills/right-side/scan_right_side.py 化工
```

参数说明：

- **板块/行业**（必填）：支持三类输入——
  - **指数**：沪深300 / 中证500 / 中证1000 / 上证50 / 中证红利 / 科创50 / 创业板指
  - **板**：创业板 / 科创板（全板成分，非指数）
  - **行业/概念**：半导体 / 芯片 / 化工 / 白酒 / 光伏 / 新能源 / 医药 / 军工 ...（板块名模糊匹配，宽泛简称如「化工/有色/医药」会自动合并多个细分板块）
- **输出数量**（可选，默认 20）：输出候选数量上限。
- **`--sync`**（可选）：先增量同步本地 marketdb 到最新（可能触发下载，遇 429 限流会失败）。
- **`--full` / `--no-prescreen`**（可选）：跳过本地库 streaks 初筛，全池逐股拉新浪 K 线（更慢但召回最全）。

## 扫描流程

解析成分股池 → **（池 ≥40 只时）先用本地 marketdb streaks 初筛「量价齐升 / 连续创新高」缩小范围** → 对候选逐股拉 120 根日 K 线 → 跑右侧检测打分 → 硬门槛筛掉「未站上MA20 / 无量无突破 / ST退市风险」→ 按信号分排序**分层输出**（✅强 ≥75 为主候选、⚠️中 55~74 观察、🔸弱 <55 不显示）→ 对 top 候选做妙想主力资金确认（近5日净流入）→ **估值分位门槛**（PB/PE>70 高位标 ⚠️）→ 另输出 **🎯回踩买点候选**（趋势已确认 + 现价缩量回踩不破，可介入的右侧入场点）。开扫前先做**板块退潮检测**（查询板块近5日主力净流出则提示降级）。**成分股池用 app.board_pool，K 线走本地 duckdb（缺才回退新浪），核心不依赖 `MX_APIKEY`**；初筛后通常 10~60 秒。streaks 初筛按本地库快照（可能落后最近交易日，脚本会提示），最终打分仍逐股用本地 K 线复核，故初筛只减请求、不改变单股结论。

## 右侧检测逻辑（五层）

1. **均线多头**：MA5>MA10>MA20>MA60（多头排列，最强）> MA5>10>20 > MA5>10 > 站上 MA20。**站上 MA20 是硬门槛**（趋势修复的基本前提）。
2. **放量突破**：价格突破近 20 日 / 60 日高点（创新高）或逼近高点，配合量比 ≥1.2（放量）、≥2（显著放量）——突破有量才可信。**换手率校准**：量比是相对值，大盘股量比易虚高；换手率 ≥5% 高换手确认真放量、<1% 地量则放量存疑。**无量降级**：创 20/60 日新高或**缩量逼近前高**（量比 <1.2）都 = 假突破/滞涨嫌疑，突破分减半并标注「（无量）」，不得与放量突破同等对待——缩量逼近前高是买盘衰竭的做头信号，是右侧最危险的追高位。
3. **MACD 动量**：金叉（转强）或多头（红柱延续）。
4. **涨幅强度**：近 5 日涨幅，衡量动量持续性。
5. **资金确认**（妙想）：近 5 日主力资金净流入——「资金 + 趋势」共振的右侧最稳。

**硬门槛**：未站上 MA20 直接排除；站上 MA20 但「无突破 / 无均线多头 / 无 MACD 走强 / 无放量」任一确认，也排除（过滤死猫跳）。ST / 退市风险股排除。

## 分析框架（AI 在候选表之上生成报告）

### 一、先讲清「这是不是右侧机会」
一句话结论：当前板块/行业里**有没有**已确认启动的右侧机会，及整体趋势强弱。候选为 0（无 ✅强档）= 该板块整体尚未转强，不是右侧买点。**区分三档**：✅强(≥75) 才是「可重点看」的趋势确认票；⚠️中(55~74) 只是「观察」——趋势未完全确认，跟踪为主、不急于买；🔸弱(<55) 脚本已不显示（无增量信息）。**给结论时先说明当前是哪个档位占主导**，别把「中档观察」写成「可追」。

### 二、解读 top 候选（逐只）
对每只 top 候选讲清楚：
- **趋势**（均线状态：多头排列最强）与**突破**（创 20/60 日新高？还是仅站上 MA20？）
- **量价**（量比、换手率、5日涨幅）——放量突破才是有效突破，缩量新高要警惕
- **MACD** 是否金叉/多头确认

### 三、资金确认（妙想结果）
近 5 日主力净流入 = ✅（资金在买，右侧更稳）；净流出 = ⚠️（追高风险大，谨慎）。

### 四、买点与止损（对确认候选）
- **候选 ≠ 买点**：脚本选出的「趋势确认」票**不代表此刻该买**；突破日往往是短期高点，追在放量长阳顶是最差入场（回测 fut20 净 edge ≈ 0，追高被套多发于此）。
- **优先看 🎯回踩买点候选**：脚本已单独输出「趋势已确认 + 现价缩量回踩（2~10%）不破 MA20」的入场候选，这才是可直接介入的右侧点位；「趋势确认」表里的票要等回踩再进。
- **右侧买点**：等**回踩不破**再介入——回踩 MA5/MA10 或突破位（前高/MA20）企稳不破时买；不追高、等回踩，宁可错过。
- **止损**：跌破 MA20（每行已列「止损」价）或突破位（前高，已列「突破位」）**收盘确认**即离场；右侧追高被套 = 跌破启动位就认错，不扛单。

### 五、风险提示（每次必带）
- 右侧追的是「已启动」的票，**买点相对高，一旦突破失败（假突破）回撤快**，务必设 MA20/突破位止损
- 放量突破后常伴随回踩洗盘，别在放量长阳的最高点追
- 以上是公开行情/技术指标/资金面的分析，不构成投资建议，独立决策

## 注意事项

- **数据源**：成分股池（app.board_pool）、日 K 线（新浪）、主力资金（妙想，需 `MX_APIKEY`）。**技术面核心不依赖 `MX_APIKEY`**。
- **「真突破」与「假突破」**：放量（量比≥1.5）+ 收盘站上前高 + 次日不破前高 = 真突破概率大；无量突破 / 盘中冲高回落 = 假突破嫌疑，别追。
- **芯片 vs 半导体**：行业名「半导体」更完整，概念名「芯片」可能只命中子概念；查全行业请用「半导体」。
- **不臆造**：脚本没查到的（具体利好/题材催化）不要编造；需要时叠加 `/news-search` 查题材催化、`/sector-flow` 看板块资金是否整体流入。
- **镜像关系**：左侧（埋伏、赌反转）与 right-side（顺势、等突破确认）是两种打法；给结论时明确「当前是左侧还是右侧机会」。
