# 轻量智能选股（妙想）

用妙想 `stock_screen` 接口做一句式自然语言选股，返回结构化候选列表，适合即时、临时的选股查询（区别于 `smart_screener`/`strong_screener` 的六阶段重管线）。

## 用法

```bash
py .claude/skills/stock-screen/screen_stock.py <自然语言条件> [数量]
```

示例：

```bash
py .claude/skills/stock-screen/screen_stock.py 连续3日主力资金净流入且估值较低
py .claude/skills/stock-screen/screen_stock.py 今日放量上涨且主力资金净流入 30
py .claude/skills/stock-screen/screen_stock.py 市盈率低于20倍且净利润增长 20
```

参数说明：

- **条件**（必填）：自然语言选股条件，支持资金面（主力净流入）、估值（市盈率/市净率/历史分位）、量价（放量/换手）、技术（突破/低位）等维度组合。
- **数量**（可选，默认 20，上限 50）：返回候选数。

## 脚本输出与解读

- 结构化表格：代码、名称、行业、现价、涨跌幅、主力净额（亿元）、估值状态（较低/适中/较高 + 历史百分位）、换手率、量比。
- 查询「连续 N 日净流入」时会额外输出**主力净额逐日序列**（日期 + 当日主力净额），用于验证「连续流入」是否成立。
- 字段缺失时显示 `—`。

## 分析框架（AI 在数据包之上生成结论）

1. **筛选逻辑复述**：把自然语言条件转成明确的筛选标准，确认妙想是否准确理解。
2. **候选解读**：挑 3-5 只代表性候选，说明各自符合条件的原因（资金/估值/量价维度）。
3. **风险提示**：指出该选股逻辑的盲区（如纯资金面可能追高、低估值可能是价值陷阱），并给「入选后应再看什么」（基本面/事件/技术位）。
4. **结论**：一句话总结该条件的候选质量，是否值得进一步深挖（可接 `stock-analysis` 诊股）。

## 注意事项

- **依赖**：需在 `.env` 配置 `MX_APIKEY`（可选 `MX_APIKEY_2` 备用）。
- **与重管线的区别**：本 skill 只做一句式即时查询，不做黑名单过滤/LLM 综合评价/报告生成。需要「资金潜伏 + 估值分位 + LLM 分级」的完整选股走 `smart_screener`，需要「热门板块强势股」走 `strong_screener`。
- 条件表达越明确（指标 + 方向 + 阈值），妙想解析越准。模糊问句可能返回空或宽泛结果。
- 结构化解析失败时自动回退 `stock_screen_as_text` 打印妙想原始文本表格。
