# 行业景气雷达（sector-beta）

**自上而下选行业**：先找「正在批量出牛股 + 有动量 + 资金持续流入」的景气行业，再在行业内选股、技术择时。依据调研结论——牛股的本质是**行业 beta**（产业周期让整条链一起翻倍），不是个股技术形态。技术形态只在「行业内选股/择时」阶段用。

## 用法

```bash
py .claude/skills/sector-beta/scan_sector_beta.py [数量]        # 输出 top/bottom N（默认 15）
py .claude/skills/sector-beta/scan_sector_beta.py --history [topK]  # 历史时间序列（持续性/轮动/新晋）
```

示例：`py .claude/skills/sector-beta/scan_sector_beta.py 20`

## 三个信号

| 信号 | 含义 | 数据源 |
|---|---|---|
| 牛股密度 | 行业近 250 交易日「前复权 MAX(high)/MIN(low) ≥ 2」翻倍股数 / 成分股数 | 本地 duckdb `data/market.duckdb` |
| 板块动量 | 行业近 10 日涨跌幅 | 东财板块资金流 |
| 主力资金流 | 行业近 10 日主力净流入 | 东财板块资金流 |
| 上游商品信号 | 行业对应期货主力合约 20/60 日价格动量 + 最新基差 + 20/60 日仓单变化（领先信号，不参与打分） | 同花顺期货接口 `hithink.fetch_futures_daily` / `fetch_futures_latest_basis` / `fetch_futures_warehouse_receipts` |

综合分 = `0.5·牛股密度分位 + 0.3·动量分位 + 0.2·资金流分位`（三者各自转 0~1 分位再加权）。牛股密度是核心（行业 beta 强度），动量+资金流做右侧确认。上游商品信号是**前瞻参考**（商品价格领先 A 股对应板块：60 日上行 = 成本推动/需求回暖；基差 >0 = 现货升水/供给偏紧；仓单 20 日变化 >0 = 累库/偏空，<0 = 去库/偏多），只展示、不进综合分。

**粒度**：细分行业（东财 `m:90 t:2` 全 496 个板块），过滤成分 <15 的微型板块。这样 top 榜单直接是「元件/光模块/电子化学品」这类细分链，而非「电子」这种太粗的一级行业。

## 输出

- **TOP N 主线行业**：按综合分降序，附成分数/牛股数/密度/10日涨跌/主力净流入/主力最大股/上游商品动量
- **BOTTOM N 落后行业**：同理
- **🔥 上游商品景气**：映射行业对应的期货主力合约 20/60 日动量 + 最新基差 + 仓单 20 日变化降序，作为领先信号
- 每次运行结果落库 `data/sector_beta.duckdb` 表 `sector_rank` + `commodity_rank`（同日重跑覆盖，幂等）

## 分析框架（AI 在榜单之上生成报告）

### 一、主线结论
一句话：当前主线行业是什么、依据三信号共振到什么程度。牛股密度高 + 动量正 + 资金净流入 = 真主线；只有密度但动量为负/资金流出 = 行业见顶或退潮，警惕。

### 二、解读 top 行业（逐只）
- **牛股密度**：翻倍股占成分比，越高越说明是「整条链一起涨」的产业周期，而非个别票炒作
- **动量 + 资金流**：10 日还在涨、主力还在净流入 = 景气仍在持续；动量转负/资金流出 = 退潮信号
- **主力最大股**：可作为行业内龙头候选的线索（真正龙头确认需叠加个股分析）

### 三、持续性 / 轮动（`--history`）
读历史表看：
- **连续上榜**：连续 N 期仍在 top K = 真主线（非一日游），持续性越长越值得参与
- **新晋 top**：首次进入 = 轮动/新主线启动信号，优先关注
- **排名上升**：景气在强化；排名下滑 = 景气衰减

### 四、行业内选股（下一步）
主线行业确定后，再用 `left-side`/`right-side`（行业内超跌埋伏/突破追涨）或 `dragon-pullback`（龙头回调）在**该行业成分内**选标的，配合技术形态择时。本 skill 只负责「选行业」。

### 五、风险提示（每次必带）
- 牛股密度是**滞后**指标（已经涨了才进榜），顶部追入风险高；优先选「动量还在、资金还在流入」的行业，回避「密度高但已放量退潮」的
- 以上是公开行情/技术指标的分析，不构成投资建议，独立决策

## 注意事项

- **数据源**：本地 duckdb（前复权日K，需 `data/market.duckdb` 已同步）+ 东财板块资金流（免费）。**不依赖 `MX_APIKEY`**，但需本地库（miniconda python，见 `app/kline_local.py` 自动切解释器）。上游商品信号需 `HITHINK_FINANCE_API_KEY`（同花顺期货接口），缺 key 时静默跳过、只展示三信号。
- **翻倍口径**：`MAX(high)/MIN(low) ≥ 2`（近 250 交易日前复权），比「收盘翻倍」宽松，是「这行业有没有批量出过牛股」的密度代理，不是精确涨幅。
- **本地库落后**：牛股密度按本地库最新日期算，若库落后多日需先 `/marketdb-sync` 同步，否则密度偏旧（脚本会打印数据日）。
- **行业 vs 概念**：本 skill 用的是东财「行业板块」（细分），不含概念板块（如「AI 算力」这种跨行业概念）；概念主线另走 `market-heat`/`sector-flow` 的概念板块资金流。
- **一期边界**：研报/政策确认层（叠 `/news-search`）、行业内龙头领涨股为二期，本版未做。
