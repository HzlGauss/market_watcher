# 龙回头检测（dragon-pullback）

对单只股票做「龙回头」形态检测：**龙头股强势首波上涨后，首次缩量浅回调不破关键位，赌其二次启动**。脚本只取数算指标，输出 6 段数据包；「是否构成龙回头 / 能否参与 / 买点与止损」由 AI 依据下方框架生成。

## 用法

```bash
py .claude/skills/dragon-pullback/analyze_dragon_pullback.py <代码> [名称] [天数]
```

示例：

```bash
py .claude/skills/dragon-pullback/analyze_dragon_pullback.py 002512 达华智能
py .claude/skills/dragon-pullback/analyze_dragon_pullback.py 300432 富临精工 90
```

参数说明：

- **代码**（必填）：6 位 A 股代码（个股；ETF/指数无「龙头/连板」概念，不适用）。
- **名称**（可选）：提升妙想查询精度，可省略。
- **天数**（可选，默认 60，上限 120）：拉取的日 K 线根数。≥60 才能算 MA60；龙回头需覆盖「起涨→首波→回调」完整过程，建议用默认 60 或更大。

### 批量扫描（找候选）

不确定看哪只时，先用批量版从近 N 个交易日的涨停股池里筛出潜在龙回头候选：

```bash
py .claude/skills/dragon-pullback/scan_dragon_pullback.py [回溯天数] [输出数量]
```

示例：`py .claude/skills/dragon-pullback/scan_dragon_pullback.py 10 20`（回溯 10 个交易日涨停池，输出 top 20）。

批量版流程：拉近 N 日涨停股池（含连板数/所属行业）→ 板块热度聚合 → 逐股拉日K线跑六层检测打分 → 硬门槛筛掉「还在连板/已破位退潮」→ 按信号分排序输出候选表。**数据源 akshare 涨停股池 + 新浪 K 线，不依赖 MX_APIKEY**；约 1~2 分钟（约 270 只候选逐股拉 K 线）。批量版是初筛，确认单只买卖点/止损时再用上面的单股版细看。

脚本输出 **6 段数据包**：

- **① 龙头识别**：板块（主板/创业/科创/北交所，涨跌停幅度不同）+ **连板高度**（连续涨停天数、是否仍在连板）+ **龙虎榜**（是否上榜 / 净买额 / 买卖比 / 换手 / 上榜原因）
- **② 首波上涨强度**：起涨点（日期+低点）→ 首波高点（日期+价）、首波涨幅、拉升天数、距顶点交易日数、**放量对比**（首波均量 vs 起涨前均量）、首波强度标签
- **③ 回踩质量（核心）**：回调低点 + 回撤%、现价回撤%、**黄金分割位**（回撤吃掉首波涨幅的比例，0.382/0.5/0.618）、**缩量判断**（回调均量 vs 首波均量）、**破位检查**（MA5/10/20/起涨平台）、回调天数
- **④ 企稳信号**：止跌 K 线形态（长下影/锤子/看涨吞没）、RSI/KDJ/MACD 位置、是否超卖
- **⑤ 二次启动确认**：最新 K 线阴阳 + 放量、是否站上 MA5、是否突破回踩区间高点、当日主力净流入方向
- **⑥ 结论聚合**：6 项 checklist（龙头强度/首波放量/缩量回调/回调未过深/不破位/企稳二次启动）+ **信号分级**（✅/⚠️/❌）+ 参考关键位（起涨平台/首波高点/回调低点/MA5/10/20/技术支撑压力）

## 分析框架（AI 在数据包之上生成报告）

严格按以下 7 段组织输出。**核心：先判「是不是龙、回没回头」，再判「回踩健不健康」，最后判「能不能上、买点止损」。**

### 一、是不是龙头（【1】）
先给**一句话结论**（是/不是龙头，及依据）。从「①」提炼：
- **连板高度**：2 连板以上 + 首波涨幅 ≥20% 是龙头标配；仅首波涨 15% 无连板算「中等」；低于此算「跟风/偏弱」。
- **龙虎榜**：上榜 + 净买入为正 + 买卖比 >1 = 游资/机构真金介入；未上榜 = 非当日资金主战场，龙头成色打折扣。
- **题材**：脚本【1】不直接查题材，需结合名称/行业常识判断其背后有无硬催化（政策/业绩/事件）。**板块地位**（是否板块内最强）脚本无法横向比较，可提示叠加 `/sector-flow` 或 `/stock-screen` 看板块热度，或 `/news-search` 查题材。

### 二、首波够不够强（【2】）
从「②」判断首波是否具备「回头」的资本：
- **涨幅与天数**：首波涨幅 ≥20%、拉升天数适中（急拉为主）最好；涨幅 <15% 或阴跌爬升 = 不具备龙头属性。
- **放量**：首波均量 ≥ 起涨前 1.2 倍 = 主力真进场；未放量 = 拉高存疑，回踩后易走弱。
- **关键结论放句首**：如「首波涨幅 xx%、连板 x、放量确认，具备龙头强度」。

### 三、回踩健不健康（【3】，最核心）
这是龙回头成败的关键，逐条核对：
- **幅度**：现价回撤落在首波涨幅的 **0.382~0.5 区间**最健康（风险释放、未破位）；<0.2 是「几乎没回调」、还在高位追高风险；>0.618 属「回头过深」，转弱概率大。注意黄金分割以**收盘价（现价）**计，盘中插针不算。
- **缩量**：回调均量 < 首波 0.7 倍 = 抛压衰竭、主力未出货（✅）；回调**放量**（≥首波量）= 疑似出货，直接弃。
- **不破位**：现价不破 MA10/起涨平台；站回 MA5 上方更佳。**跌破起涨平台 = 龙回头失败**。
- **时间**：回调 3~5 日最佳，拖过两周人气散、失败率高。
- 若【2】【3】显示「顶点即最近一日」= 尚未回调，明确写「首波仍在进行/刚见顶，还没『回头』，等首次回调出现」。

### 四、企稳了没有（【4】）
- **止跌 K 线形态**（长下影/锤子/看涨吞没）+ 缩量 = 左侧埋伏的可观察信号。
- **超卖提示**：RSI<30 / KDJ J<0 说明跌得急，但超卖 ≠ 见底，**必须等止跌确认**，避免接飞刀。

### 五、二次启动与买点（【5】+ 关键位）
- **右侧买点（更稳）**：放量阳线站上 MA5 + 突破回踩区间高点 + 当日主力净流入回正，三项共振 = 二次启动确认。
- **左侧埋伏（激进）**：仅在有「缩量浅回调 + 止跌形态」且未破位时考虑，小仓试。
- **买点参考**：用「②起涨平台 / ④技术支撑 / 现价」给分档，**回调低点与起涨平台之间是安全垫区间**。

### 六、止损与风控（关键位）
单独一行写清：
- **止损**：跌破**回调低点**（近期）或**起涨平台**（底线）即止损，收盘确认。
- **仓位**：左侧轻仓试、右侧确认再加；题材退潮/大盘转弱时「回头」常变「补跌」，宁可不做。
- **题材持续性**：龙头回头能否成，一半看题材风口是否还在。

### 七、结论（表格 + 一句话）
先给**一句话结论**（✅ 可参与 / ⚠️ 观察等待 / ❌ 放弃），严格遵循脚本【6】的信号分级方向（AI 可结合题材/板块地位在 ⚠️ 边界处微调，但不得把脚本判 ❌ 的写成可参与）：

| 情形 | 结论 |
|---|---|
| ✅ 龙头 + 缩量浅回调 + 未破位 + 企稳/二次启动 | 可参与，给买点与止损 |
| ⚠️ 形态接近但回调未缩量 / 缺二次启动确认 | 观察等待，说明等什么信号转可参与 |
| ❌ 非龙头 / 首波弱 / 回调过深 / 放量回调 / 破位 | 放弃，复述原因 |

**免责声明**（每次必带）：以上是基于公开行情/资金流/龙虎榜/技术指标的分析，不构成投资建议；龙回头是高风险短线博弈，需设好止损、独立决策。

## 注意事项

- **数据源**：实时快照（新浪+腾讯）、日 K 线（新浪，AKShare 兜底）、当日资金流（东财 fflow）、龙虎榜（AKShare）、近 5 日资金流（妙想，可选）。**核心不依赖 `MX_APIKEY`**（脚本当前未强制要求；龙虎榜依赖 `pip install akshare`，缺装时【1】龙虎榜显示「未上榜」，需提醒用户补装）。
- **涨停口径**：按板块涨跌停幅度（主板 ±10%、创业/科创 ±20%、北交所 ±30%）+ 0.6pp 容差判断封板；ST 股 5% 未特殊处理，ST 一般不作为龙回头标的。
- **首波识别口径**：首波顶点 = 近 N 日最高 high，起涨点 = 顶点前最低 low；若股票已走多波或 N 日窗口内无清晰单波拉升，识别可能失真，AI 需结合【2】日期区间合理性判断。
- **不臆造**：脚本没查到的（题材催化、板块横向地位、席位级游资明细）不要编造；需要时叠加 `/sector-flow`、`/news-search`、`/fund-flow`。风险点与机会是 AI 综合判断，不是脚本直接输出。
- **A 股 T+1**：普通 A 股当日买入次日才能卖，追龙回头只能持有至次日或后续，提示短线波动风险。
- **预测是概率判断**：始终给关键位与触发条件，避免「必涨/必回头」的绝对表述。
