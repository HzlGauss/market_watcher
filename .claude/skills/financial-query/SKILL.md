# 金融数据问答（妙想）

用妙想 `query` 接口做自然语言 → 金融数据查询，覆盖行情、财务、资金流、筹码、估值、分红等任意维度，返回结构化表格。

## 用法

```bash
py .claude/skills/financial-query/query_finance.py <自然语言问题>
```

示例：

```bash
py .claude/skills/financial-query/query_finance.py 招商银行 市盈率 历史分位
py .claude/skills/financial-query/query_finance.py 贵州茅台 近5日主力资金净流入
py .claude/skills/financial-query/query_finance.py 宁德时代 最新财报 净利润 营收 同比增长
py .claude/skills/financial-query/query_finance.py 沪深300 市盈率 市净率
```

参数说明：

- **问题**（必填）：完整自然语言问句，可包含证券代码/名称 + 指标关键词。妙想会自动识别证券与指标类型。

## 脚本输出与解读

- 每个妙想返回的 `dataTableDTO` 渲染为一张表：标题 + 证券全称/代码 + 列名 + 行数据。
- 常见维度与问句示例：
  - **行情**：`XX 最新价 涨跌幅 成交量`
  - **财务**：`XX 最新财报 净利润 营业收入 同比增长`
  - **资金流**：`XX 近5日主力资金净流入`
  - **筹码**：`XX 机构持股比例`、`XX 股东户数`
  - **估值**：`XX 市盈率 历史分位`、`XX 市净率`
  - **分红**：`XX 分红 股息率`
- 数值保留原始字符串（含「万元/亿元/%」单位），由 AI 解读时归一化。

## 分析框架（AI 在数据包之上生成结论）

1. 从表格提取关键指标与最新值，说明口径（单值 vs 多期序列）。
2. 结合行业常识判断该值的相对水平（高/中/低）。
3. 一句话总结该问句的答案，必要时给趋势/对比。

## 注意事项

- **依赖**：需在 `.env` 配置 `MX_APIKEY`（可选 `MX_APIKEY_2` 备用）。
- **问句越具体越准**：带上证券全名/代码 + 明确指标名（如「市盈率历史分位」而非「估值」）能提升识别精度。
- **多表返回**：一个问句可能返回多个 `dataTableDTO`，脚本会全部渲染（如「财报」可能同时返回营收、净利润、ROE 多张表）。
- 结构化解析失败时自动回退 `query_as_text` 打印妙想原始格式化文本。
