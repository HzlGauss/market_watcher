# 持仓个股消息面扫描（利好/利空）

对持仓中的普通 A 股个股逐只做消息面体检：拉取最近的新闻、公告、研报，用大模型判定综合影响方向。

## 用法

```bash
py .claude/skills/holdings-news/scan_holdings_news.py [小时]
```

参数说明：

- **小时**（可选，默认最近 7 天）：只保留最近 N 小时内的资讯。传 `24` = 最近 24 小时。

## 数据源与分工

| 数据源 | 用途 | 依赖 |
|---|---|---|
| 妙想 `fin_search_structured`（主） | 新闻 + 公告 + 研报，含评级/机构/关联证券 | `.env` 配 `MX_APIKEY` |
| akshare `stock_news_em`（兜底） | 妙想无结果时，拉东财个股新闻 | `pip install akshare` |
| DeepSeek `LLMClient`（判定） | 逐只判定利好/利空/中性 + 强度 + 关键事件 | `DEEPSEEK_API_KEY` |

## 脚本输出与解读

- 顶部：扫描标的数量、时间窗口、数据源。
- **汇总表**：`方向 | 强度 | 名称 | 关键事件`，按「利空强 → 利好强 → 中性」排序（利空排前便于先看风险）。
- **明细**：每只票 `方向·强度（资讯条数）` + 一句话判断依据。
- LLM 未启用时，自动回退为贴出原始资讯列表供人工判断。

## 分析口径（大模型判定的规则）

1. **方向**：利好 / 利空 / 中性。
2. **强度**：强 / 中 / 弱（消息确定性与力度）。
3. **权重**：近 1-2 日资讯权重大于更早资讯；业绩超预期/增持/回购/中标/政策利好偏利好；减持/解禁/立案处罚/业绩暴雷/下调评级偏利空。
4. **中性**：资讯稀少或方向互相抵消。

## 注意事项

- **个股过滤**：用 `app.helpers.is_a_share_stock()` 按号段排除 ETF/基金/B股，只扫普通 A 股（60/68/00/30 开头）。
- **时效**：非交易时段/收盘后运行返回的是最新已披露资讯，适合复盘与次日预案；盘中运行可捕捉突发公告。
- **相关性过滤**：拉到的资讯会先按「标题/正文/关联证券含公司名或代码」过滤，过滤后为空则回退全部，避免误丢。
- **成本**：逐只单独调用 DeepSeek（上下文隔离、判断更聚焦），持仓个股数量级（十余只）下耗时约 1 分钟内。
