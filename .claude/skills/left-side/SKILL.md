# 左侧选股扫描（left-side）

对**指定板块/行业**做左侧机会扫描：在成分股里找出「**跌得够深、抛压衰竭（缩量）、指标超卖、有早期企稳迹象、长期趋势尚未完全破坏**」的票，赌其见底反转。这是**左侧交易**——在底部右侧确认之前埋伏，风险更高、赔率更大。

与 `right-side`（右侧：突破/多头确认后顺势追）互为镜像。与 `golden-pit` 的关系：golden-pit 是「白马蓝筹 + 深坑」的左侧特例，本 skill 是**不限白马成色的泛化版**——任何板块/行业里的超跌股都扫。

## 用法

```bash
py .claude/skills/left-side/scan_left_side.py <板块/行业> [输出数量]
```

示例：

```bash
py .claude/skills/left-side/scan_left_side.py 半导体
py .claude/skills/left-side/scan_left_side.py 创业板 20
py .claude/skills/left-side/scan_left_side.py 沪深300 15
py .claude/skills/left-side/scan_left_side.py 化工
```

参数说明：

- **板块/行业**（必填）：支持三类输入——
  - **指数**：沪深300 / 中证500 / 中证1000 / 上证50 / 中证红利 / 科创50 / 创业板指
  - **板**：创业板 / 科创板（全板成分，非指数）
  - **行业/概念**：半导体 / 芯片 / 化工 / 白酒 / 光伏 / 新能源 / 医药 / 军工 ...（板块名模糊匹配，宽泛简称如「化工/有色/医药」会自动合并多个细分板块）
- **输出数量**（可选，默认 20）：输出候选数量上限。

## 扫描流程

解析成分股池 → 逐股拉 250 根日 K 线 → 跑左侧检测打分 → 硬门槛筛掉「未明显回调 / 仍在下跌初期」→ 按信号分排序输出候选表 → 对 top 候选做妙想基本面/估值确定性门槛（估值分位/ROE/净利同比）。**成分股池用 app.board_pool（指数成分 akshare + 东财 clist 板块/行业），K 线走新浪，核心不依赖 `MX_APIKEY`**；约 1~4 分钟（视成分股数量，创业板全板 1400+ 只约 4 分钟）。

## 左侧检测逻辑（六层）

1. **超跌深度**：现价距近 120 日高点回撤%，`≥12%` 才构成左侧机会（硬门槛），≥20% 加分、≥30%~40% 深度超跌最高分。
2. **缩量抛压衰竭**（核心）：回调段均量 vs 高点前 20 日均量，`<0.6` 抛压衰竭最健康；`≥1.0` 放量 = 疑似出货，不加分。
3. **超卖指标**：RSI ≤30（严重超卖）、KDJ J 值 ≤0、MACD 低位金叉 = 反转前兆。
4. **企稳迹象**：止跌 K 线（长下影/锤子/看涨吞没）、站上 MA5/MA10 = 初步止跌。
5. **未破长期趋势**：站上 MA120（半年线）/ MA250（年线）加分；跌破者风险更高（仍可扫，但须估值低 + 超卖补偿）。
6. **估值低位**（妙想，确定性门槛）：PB 历史分位越低越安全；净利同比 <0 = ❌ 真跌（暴雷，排除）；ROE <8% = ⚠️ 成色弱。

## 分析框架（AI 在候选表之上生成报告）

### 一、先讲清「这是不是左侧机会」
一句话结论：当前板块/行业里**有没有**值得埋伏的左侧机会，及整体超跌程度。若候选为 0，说明该板块整体处于「未回调」或「已破位走坏」，不是左侧买点区域。

### 二、解读 top 候选（逐只）
对每只 top 候选讲清楚：
- **跌了多少**（回撤%）、**缩没缩量**（缩量比）、**超卖没超卖**（RSI/J值/MACD）
- **企稳了没**（站 MA20？止跌形态？）——左侧要的是「跌得差不多 + 有止跌苗头」，不是「已经涨起来」（那是右侧）
- **长期趋势坏没坏**（站 MA120/250 与否）——站上 = 安全边际高；跌破 = 赌超跌反弹，仓位要更小

### 三、确定性门槛（妙想结果）
严格遵循脚本给出的基本面/估值判定，**不得把 ❌/⚠️ 写成「可参与」**：
- ❌ 真跌（净利同比<0）→ 是「基本面恶化」不是「错杀」，放弃
- ⚠️ 估值高（PB分位>70）→ 只是「贵了回落」，安全垫不足
- ⚠️ 成色弱（ROE<8%）→ 长期盈利差，左侧埋伏价值低
- ✅ 通过 → 可结合技术面给买点区间与止损

### 四、买点与止损（对确认候选）
- **左侧买点**：现价下方分批埋伏（左侧不打满，留补仓空间），或等站上 MA20 + 放量 = 右侧确认再加
- **止损**：跌破近期低点（坑底）或 MA120 收盘确认，纪律离场；左侧失败 = 补跌，不可扛单

### 五、风险提示（每次必带）
- 左侧 = 赌反转，**可能继续跌、磨底时间不可测**，务必分批 + 止损
- 回撤 >45% 的「⚠️深」候选，跌得过深大概率非错杀而是暴雷，必须先查基本面
- 以上是公开行情/技术指标/基本面的分析，不构成投资建议，独立决策

## 注意事项

- **数据源**：成分股池（app.board_pool）、日 K 线（新浪）、基本面+估值（妙想，需 `MX_APIKEY`）。**技术面核心不依赖 `MX_APIKEY`**。
- **「错杀」与「真跌」的分野**：脚本只算技术形态，是否「错杀」必须靠妙想基本面确认——ROE 仍高、盈利未大幅下滑、估值历史低分位，三者支撑「错杀」；缺一则警惕价值陷阱。
- **芯片 vs 半导体**：行业名「半导体」更完整（成分更全），概念名「芯片」可能只命中「模拟芯片设计」等子概念；查全行业请用「半导体」。
- **不臆造**：脚本没查到的（具体利空事件、机构持仓）不要编造；需要时叠加 `/news-search` 查利空/减持/解禁、`/fund-flow` 查主力资金是否回流、`/sector-flow` 看所属板块是否企稳。
- **镜像关系**：左侧（埋伏、赌反转）与 right-side（顺势、等突破确认）是两种打法，同一只票可能在左侧 scan 与右侧 scan 中处于不同阶段；给结论时明确「当前是左侧还是右侧机会」。
