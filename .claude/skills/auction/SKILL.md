# 早盘竞价雷达（auction）

拉取**全市场短线风向标竞价基准 + 个股集合竞价快照**，算**竞价涨跌幅 / 量比 / 竞价换手 / 昨量比 / 未匹配量**，输出竞价强弱数据包。脚本只取数排名，「竞价强弱 / 情绪周期」结论由 AI 依据下方框架生成。

与其他 skill 的分工：
- `intraday-signal` = 盘中决策（实时快照 + 资金流 + 5 分钟 K 线支撑压力，做 T 挂单）；
- **本 skill** = 9:15–9:25 集合竞价的**盘前强弱**（竞价承接/抢筹/抛压），是盘前决策的「探针」，早于盘中数据。

## 用法

```bash
py .claude/skills/auction/scan_auction.py                      # 默认扫自选+持仓 A 股
py .claude/skills/auction/scan_auction.py 半导体                # 扫指定板块/行业成分股
py .claude/skills/auction/scan_auction.py 600519,000333,300750 # 扫指定代码列表
py .claude/skills/auction/scan_auction.py 半导体 20             # 指定板块 + 输出上限
```

脚本输出 **2 段数据包**：

- **【1. 短线风向标 · 全市场竞价基准】**：服务端返回的全市场竞价情绪标签（tags，原样保留，不自行推导），如龙头/补涨/退潮/分歧等。
- **【2. 个股竞价强弱排名】**：目标池按竞价涨跌幅降序，列竞价价/竞价涨跌/量比/竞价换手/昨量比/未匹配量，并统计 `>+3%` 强势高开 / `<-3%` 弱势低开家数。

## 分析框架（AI 在数据包之上生成报告）

### 一、情绪风向标（【1】）
- **风向标 tags** 是短线情绪的「风向」：出现「龙头/强势」类标签 = 竞价情绪偏强；「退潮/分歧/弱势」类 = 偏弱。
- 结论要**引用服务端原标签**，不根据涨跌幅自行脑补标签。

### 二、个股竞价强弱（【2】）
- **高开 + 量比大 + 昨量比高 + 未匹配量大** = 抢筹式高开，资金竞价抢筹，开盘偏强。
- **高开 + 量比小 / 换手低** = 虚高开，承接不足，谨防高开低走。
- **低开 + 未匹配量大** = 抛压沉重，竞价出逃，开盘偏弱。
- **低开 + 量比小 + 未匹配量小** = 缩量低开，观望为主，未必恐慌。
- 结合风向标：风向标偏强 + 个股高开抢筹 = 可顺势；风向标偏弱 + 个股高开 = 冲高兑现风险大。

### 三、结论（一句话 + 操作提示）
先给**一句话结论**（今日竞价情绪强弱 + 哪些票竞价最强/最弱 + 该追还是该等），再给操作提示（强势抢筹→开盘关注/竞价打板、虚高开→开盘冲高减仓、弱势低开→规避/防守）。

**免责声明**（每次必带）：以上基于公开集合竞价数据，不构成投资建议；竞价波动大、9:25 前可撤单，务必独立决策、设好止损。

## 注意事项

- **数据源**：同花顺官方金融数据（`/api/a-share/auction/snapshot` + `/api/a-share/auction/short-term-benchmark`，需 `.env` 配置 `HITHINK_FINANCE_API_KEY`，无 key 直接报错）。**不依赖 `MX_APIKEY`**。
- **只支持 A 股**：竞价快照只支持 `.SH/.SZ/.BJ` A 股，ETF/LOF/基金/指数/B 股不支持——脚本已自动过滤自选/持仓里的非 A 股。
- **时段**：集合竞价 9:15–9:25（9:25 定出开盘价）。9:25 后数据为 `final` 终态；9:15–9:25 为 `live` 实时；非竞价时段返回 `not_ready`/`suspended`（脚本会打印 data_status，不得用零值/模拟行情补齐空字段）。
- **默认目标池**：`holdings.csv` + `watchlist.csv` 里的 A 股（去重，持仓优先）；也可传板块/行业名（走 `board_pool` 解析成分）或逗号分隔代码列表。
- **不臆造**：脚本没查到的（具体竞价催化消息、龙虎榜资金）不要编造，需要时叠加 `/news-search` 查题材催化、`/market-heat` 看热点方向。
