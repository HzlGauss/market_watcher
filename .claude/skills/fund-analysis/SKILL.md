# 主动基金诊基（妙想 + 东财净值）

对单只场外开放式基金做一次诊断：净值绩效 + 基准对比 + 权威评级 + 持仓风格 + 经理评价 + 规模配置，输出 4 段数据包，再由 AI 生成结论。

## 用法

```bash
py .claude/skills/fund-analysis/analyze_fund.py <代码> [名称]
```

示例：

```bash
py .claude/skills/fund-analysis/analyze_fund.py 005827 易方达蓝筹精选
py .claude/skills/fund-analysis/analyze_fund.py 110011
py .claude/skills/fund-analysis/analyze_fund.py 005827
```

参数说明：

- **代码**（必填）：6 位场外开放式基金代码。
- **名称**（可选）：提升妙想查询精度；省略时脚本会尝试用妙想自动补全基金全称。

## 脚本输出与解读

- **① 基本信息**：代码/全称/最新净值/日涨跌幅/跟踪区间（东财净值 + 妙想补全全称）。
- **② 净值绩效指标**（东财近 1 年净值计算）：年化收益率、年化波动率、夏普比率、最大回撤、卡玛比率、胜率、盈亏比、数据点数。
- **③ 相对基准**：业绩比较基准 + 超额收益、跟踪误差、信息比率、Beta、Alpha（基准从东财 F10 自动识别）。
- **④ 妙想深度数据**（需 `MX_APIKEY`）：晨星/银河权威评级、前十大持仓与行业分布、阶段涨幅与四分位排名、基金经理任职回报、基金规模与资产配置。

## 分析框架（AI 在数据包之上生成报告）

### 一、基金是什么
从①④提炼：基金类型（偏股/偏债/混合/指数增强）、跟踪或比较基准、现任经理、规模、成立时间。

### 二、赚钱能力与风险（关键结论放句首）
从②③提炼，用「关键结论：xxx」开头：
- **收益**：年化收益率（②）对比同类，看绝对水平。
- **风险**：最大回撤（②）与年化波动率，判断回撤是否可承受。
- **性价比**：夏普比率（>1 优秀、<0.5 偏弱）、卡玛比率（收益/回撤）。
- **相对基准**：Alpha（正=跑赢基准、负=跑输）、Beta（偏离基准的激进程度）、信息比率（主动管理的稳定超额能力）。

### 三、持仓风格与经理
从④提炼：前十大持仓的行业/风格集中度（集中=风格漂移风险大）、经理任职回报与稳定性（频繁换经理是风险）。

### 四、综合评价与操作建议（表格）
给出一句话结论 + 依据表，并落到动作：
- **是否值得买**：结合绩效 + 评级 + 持仓风格 + 当前市场风格（注意：脚本数据不含实时市场情绪，AI 可补知识判断）。
- **持有/加仓/减仓/赎回**：业绩持续跑输基准且 Alpha 长期为负 → 考虑减仓/赎回；Alpha 稳定为正 + 回撤可控 → 可持有/加仓。
- **风险点**：风格过于集中、规模过大影响灵活性、经理变动、回撤超承受能力。

## 注意事项

- **依赖**：净值/基准走东财直连（无需 `.env`）；妙想深度数据（评级/持仓/经理/规模）需在 `.env` 配置 `MX_APIKEY`。
- **仅限场外开放式基金**：ETF/场内基金走 `etf-grid` 或 `stock-analysis`（有 ETF 分支）。
- **净值数据窗口**：`_fetch_nav` 拉约 250 个交易日（近 1 年），指标为近 1 年滚动；不足 240 日会标注「数据不足一年」。
- **基准对比精度**：基准指数取周线数据近似，Alpha/Beta 为估算值，用于相对强弱判断而非精确归因。
- 妙想 5 个维度按顺序串行查询（每个约 0.5s），单只基金约需数秒；无 key 时仅输出①②③。
