# 查询板块资金流排名（东方财富）

查询 A 股各板块（行业/概念/地域）的主力资金流入排名，按主力净流入降序排列。

## 用法

运行打包脚本，传入可选周期、板块类型和显示数量：

```bash
py .claude/skills/sector-flow/query_sector_flow.py [周期] [板块类型] [数量]
```

示例：

```bash
py .claude/skills/sector-flow/query_sector_flow.py                # 行业板块 5日资金流排名（全部）
py .claude/skills/sector-flow/query_sector_flow.py 今日           # 行业板块 今日资金流排名
py .claude/skills/sector-flow/query_sector_flow.py 10日 概念      # 概念板块 10日资金流排名
py .claude/skills/sector-flow/query_sector_flow.py 5日 地域       # 地域板块 5日资金流排名
py .claude/skills/sector-flow/query_sector_flow.py 10日 行业 20   # 行业 10日，前20净流入+后20净流出
py .claude/skills/sector-flow/query_sector_flow.py --top 15       # 行业 5日，前15+后15
```

参数说明：

- **周期**（可选，默认 `5日`）：`今日` / `5日` / `10日`（也接受 `1` / `5` / `10` / `今天`）。
- **板块类型**（可选，默认 `行业`）：`行业` / `概念` / `地域`。
- **数量**（可选，默认打印全部）：前 N 名净流入 + 后 N 名净流出，中间省略；可用位置参数（如 `20`）或 `--top N`。

## 脚本输出与解读

- 表格按**主力净流入降序**（净流入最多在前）。
- 金额单位为**亿元**，`+` 为净流入、`-` 为净流出。
- `主力净流入 = 超大单 + 大单`，反映大资金方向。
- 列：排名、板块、涨跌幅、主力净流入、净占比、主力净流入最大股。
- `—` = 该字段无数据。

## 注意事项

- **数据源 + 三级兜底**：首选东方财富数据中心「资金流向-板块资金流」，直连东财 clist 接口（无鉴权，无需 `.env` 配置）；底层走 `push2delay` 子域优先、`push2` 兜底，规避反爬断连。**东财 push2 若被 IP 封锁**（连接被重置，`RemoteDisconnected`），自动降级为：① 本地缓存快照（`state/sector_flow_cache.json`，最近一次东财实时结果，标注时间戳）→ ② 妙想逐板块（需 `.env` 配置 `MX_APIKEY`，逐个查 ~28 个主流行业的主力净流入并排名）。来源会标注在输出标题里：`东财实时` / `缓存快照(时间)` / `妙想逐板块`。
- **妙想兜底的局限**：仅覆盖**行业板块**（概念/地域无子集清单，不适用）；只返回 ~28 个主流行业的**子集排名**，且**涨跌幅/净占比/主力净流入最大股三列为空**（妙想接口不返回这些字段）；「10日」周期仅能累加近 6 个交易日（best-effort）；受妙想限流影响，个别行业偶发缺失属正常。
- **周期上限**：东财该接口只提供「今日 / 5日 / 10日」三档固定聚合，不支持任意 N 日。要任意 N 日需走历史逐日接口自行累加（`app/data_fetcher.py` 的 `STOCK_FLOW_DAILY_API`，暂未封装）。
- **时效**：实时（仅交易时段有效），盘中会随行情刷新，非交易时段可能无数据或为上一交易日快照。
- **口径**：行业板块约 86 个、概念/地域更多；东财实时接口失败时走缓存/妙想兜底，全部失败才返回空列表（脚本提示「接口不可达」）。
