# 翻倍股启动前筛选（doubling-stock）

按本地 DuckDB 全历史回测（2016-09~2026-11，5507 只，滚动未来 1 年翻倍标签，基线 5.25%）验证过的因子，筛「翻倍股启动前」候选。**脚本只取数算指标、出名单；是否值得下手、买点止损由 AI 依据下方框架逐只判断。**

回测结论（详见 memory `doubling-stock-prelaunch-signals.md`）：

- **翻倍率严格随市值递减，超额只在微盘**：<10亿 34.3%(6.5×)、10-20亿 10.3%(2×)、20-30亿 5.8%(1.1×)、30亿以上全部低于基线（30-100亿"小盘"是伪信号）。
- **超跌是唯一强叠加因子**：距 1 年高点回撤 >40%（越深越好），`<10亿+超跌>40%` 翻倍率 46.7%(8.9×)。
- **上市 2-5 年 = 降风险不升收益**（避开 <1 年次新解禁抛压 + 老壳股）。
- **基本面闸门 = 同收益低风险**：净利转正/加速不抬翻倍率（≈亏损），但把腰斩率压到 1/4（盈亏比 217 vs 57）。

## 用法

```bash
py .claude/skills/doubling-stock/scan_doubling.py [输出数量] [--no-age] [--include-st]
```

示例：`py .claude/skills/doubling-stock/scan_doubling.py 30`（输出 top 30）。

参数：

- **输出数量**（可选，默认 50）：每档输出的候选数。
- **`--no-age`**：去掉「上市 2-5 年」门槛（输出 Tier B，会混入 ST 老壳股，ST 会标注）。
- **`--include-st`**：Tier A 也纳入 ST（默认剔除）。

脚本全程只读本地 `data/market.duckdb`（日K + 三张报表 + 估值），**零网络、不依赖 `MX_APIKEY` / `HITHINK_FINANCE_API_KEY`**。跑前先确保本地库已同步到最新报告期（`py tools/marketdb_local.py` 或相关 sync），否则净利同比会落后。

## 三层筛选逻辑

脚本内置三段 SQL（`scan_doubling.py`）：

1. **技术闸门**：市值 = 最新股东权益合计 × PB(MRQ)（亿）；回撤 = 现价 / 近 260 日最高收盘 - 1；上市 2-5 年用首根 K 线日代理（本地库日 K 自 2016-09 起，2016 前上市的老股首日统一显示 2016-09-14，会被 2-5 年窗口自然排除）。门槛：`市值<20亿 且 回撤<-40% 且 交易日≥200`。
2. **基本面闸门**：净利同比 = 最新报告期净利 / 去年同期净利 - 1；「加速」= 同比 >0 且高于上一报告期同比；「转正」= 去年亏损、今年转盈利。**注意先判亏损**：`净利≤0 → 亏损` 必须排在同比判断之前，否则「两年都亏损时负÷负=正」会产生 +79% 这种假增长，把亏损扩大误判成「加速」（2026-11 实测恒合股份/一彬科技/金埔园林就是这样混进来的）。
3. **合成甜点**：`技术闸门 ∩ (加速 ∪ 转正)`，默认再剔除 ST。

## 输出解读

- **Tier A**（微盘<20亿 + 超跌>40% + 上市2-5年 + 盈利加速/转正，剔除 ST）：最干净的甜点候选，翻倍率 19-48%。
- **Tier B**（去掉上市年限门槛）：会多出 2016-2019 上市的老壳股（保壳转正/重组拉正利润），其中不少是 ST——「上市 2-5 年」门槛的价值就是把它们剔光。看 Tier B 时务必盯 ST 标注。
- **分布表**：微盘+超跌池按净利状态分组（亏损/负增长/加速/正增长/转正），一眼看出基本面闸门把多大的池子砍到多小。
- **「低基」标注**：净利同比 >300% 是去年基数近零的百分比放大，非真成长，选票看「加速」方向、别看百分比大小。

## 限制（必须诚实告知）

- **幸存者偏差**：本地库只有 5584 只当前在交易股，退市股一只不在 → 回测翻倍率被高估、退市暴雷风险不可见（2018-2026 共 265 只退市、几乎全集中微盘亏损股）。「盈利加速/转正」的价值是**压暴雷**，不是抬收益。
- **微盘甜点的现实载体是北交所**：实测甜点名单 11/12 是 920xxx（北交所），它有流动性薄 + 涨跌幅 30% + 50 万资产/2 年经验开通门槛。没开北交所权限的话，实际能买的可能只剩极少数沪深/科创板票。
- **名单是初筛**：只做「市值/回撤/上市年/净利同比」四因子，不含资金面、题材、解禁、质押、财报质量（是否靠非经常损益转正）等。下手前逐只用 `/stock-analysis` 或 `/fund-flow`、`/news-search` 复核，并查是否 ST 边缘、是否有退市风险。
- **净利同比在负数上的陷阱**：同比、加速、低基判断都只在 `净利>0` 时才有意义，脚本已内置 `净利≤0→亏损` 优先判定，勿绕过。

## AI 报告框架

对输出的候选，AI 应：

1. **先报数量与分布**：Tier A 几只、Tier B 几只（其中 ST 几只）、微盘+超跌池的净利状态分布，点明基本面闸门砍掉了多少。
2. **按市值/回撤排序贴名单**（脚本 stdout 不流到用户终端，须在答复里原样贴表），标注 ST 与「低基」。
3. **点名可下手的沪深/科创板票**（北交所需权限，先单独说明），并给风险提示：这些都是「高赔率高暴雷」标的，适合小仓位分散、设严格止损，不适合重仓。
4. **不臆造**：脚本没查到的（题材、资金、解禁、财报质量）不要编，需要时叠加对应 skill 复核。
5. **免责声明**（每次必带）：以上基于公开行情的量化初筛，不构成投资建议；翻倍股是高风险高赔率博弈，务必小仓位、分散、设止损、独立决策。
