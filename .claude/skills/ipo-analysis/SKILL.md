# 打新申购分析（新股 IPO / 新债可转债）

对单个新股（IPO）或可转债（新债）做打新决策：拉发行数据 → 规则引擎算破发概率/评分 → 结合质地与市场情绪 → 给出申购结论。

## 用法

```bash
py .claude/skills/ipo-analysis/analyze_ipo.py <代码> [名称]

# 打新日历：列出当前待申购的新股/新债
py .claude/skills/ipo-analysis/analyze_ipo.py --list [数量]
```

示例：

```bash
py .claude/skills/ipo-analysis/analyze_ipo.py 688837          # 新股（科创板）
py .claude/skills/ipo-analysis/analyze_ipo.py 113710 四方转债  # 新债（可转债）
py .claude/skills/ipo-analysis/analyze_ipo.py --list 10       # 打新日历
```

参数说明：

- **代码**（必填）：新股 6 位数字（如 688837）；新债 11/12 开头（如 113710）。
- **名称**（可选）：提升匹配精度。
- **`--list`**：列出待申购的新股/新债清单，无需代码。

## 脚本输出与解读

- **① 发行信息**：新股（板块/发行价/发行市盈率/行业市盈率/发行总数/申购上市日期/中签率）；新债（正股/转股价/转股价值/转股溢价率/信用评级/发行规模/申购日期）。
- **② 破发判断（规则引擎）**：破发概率区间 + 申购结论标签 + 综合评分（0~100）+ 关键因子。
- **③ 市场环境**：上证/深证/创业板当日涨跌。
- **④ 质地数据**（妙想，可选）：公司/正股的主营构成、行业分类、营收净利及增速、毛利率。

## 分析框架（AI 在数据包之上生成报告）

### 一、这是什么
先定性：新股还是新债、所属板块、是否已过申购窗口（`状态` 字段）。

### 二、破发风险核心判断（结论放句首，用「破发概率：xxx」开头）

**新股**看两个硬指标：
- **板块**：沪/深主板受 23 倍发行市盈率红线约束，历史破发率极低（<5%），几乎无脑打；科创板/创业板/北交所走注册制，可高 PE 甚至亏损发行，破发风险显著上升。
- **发行市盈率 vs 行业市盈率**：发行 PE 低于行业 PE（折价）→ 破发风险低；发行 PE 大幅高于行业 PE 或未披露（多为未盈利企业）→ 破发风险高。这是规则引擎评分的主因子。

**新债**看四个硬指标：
- **转股价值**（=100×正股价/转股价）：>100 破发概率极低，<90 需警惕。可转债有债底保护，破发概率整体远低于新股。
- **信用评级**（AAA/AA+/AA/AA-…）：评级越低安全垫越薄。
- **转股溢价率**：负值（折价）是好事。
- **发行规模**：越大流动性越好。

### 三、质地与市场情绪
- 从④提炼：公司/正股营收净利增速、毛利率、是否亏损、行业是否热门赛道。
- 从③判断：市场情绪好时打新收益期望高，弱市破发率上升。

### 四、申购决策（表格）
给出一句话结论 + 依据，落到动作，并标注置信度：
- **建议申购**：主板新股；折价发行的注册制新股；转股价值 >100 或评级 AA 以上的新债。
- **谨慎申购**：高 PE 注册制新股（尤其科创板未盈利）；转股价值 85~95 或评级偏低的新债。
- **放弃申购**：发行 PE 大幅高于行业 PE、大盘股 + 高 PE、或质地差的注册制新股。
- **数据不足**：发行价/市盈率未定价、行业 PE 缺失时，明确说明「待定价，信息不足」，不强行给结论。

## 注意事项

- **依赖**：核心数据走 akshare（`stock_ipo_ths` 新股 / `bond_zh_cov` 新债），需 `pip install akshare`；未安装时脚本提示无法获取。市场环境走新浪（无需 key）。质地数据走妙想（需 `.env` 配置 `MX_APIKEY`，无 key 时跳过）。
- **发行市盈率未披露**：常见于未盈利企业（科创板/北交所）或待定价新股，规则引擎会按「中高风险」处理，需结合④质地判断是否值得博。
- **申购日期格式**：新股待申购显示「MM-DD 周X」（本年），已过显示「YYYY-MM-DD」；据此判断是否仍在申购窗口内。
- **新债中签收益 vs 破发**：可转债重点不是「会不会破发」而是「上市首日能赚多少」——评级高 + 转股价值高的，破发概率极低，几乎可无脑打。
