# 自适应交易网格（支撑/压力/筹码峰，非等距）

对**指定个股或 ETF** 生成一套**非等距**网格：网格线不按固定间距平均划分，而是落在现价上下方**最近的支撑位、压力位、筹码峰**上，每条线标注方向（买/卖）、来源与强度，并判断当前是否适合做网格。

与 `etf-grid` 的区别：`etf-grid` 只做 ETF、给**等距**网格（箱体高低 ÷ 固定间距）；本 skill 个股/ETF 通用、网格线落在**真实技术位/筹码位**上，档位密度跟着支撑压力的疏密走。

## 用法

```bash
py .claude/skills/adaptive-grid/analyze_grid.py <代码> [名称] [天数]
```

示例：

```bash
py .claude/skills/adaptive-grid/analyze_grid.py 600519 贵州茅台
py .claude/skills/adaptive-grid/analyze_grid.py 510300 沪深300ETF 120
py .claude/skills/adaptive-grid/analyze_grid.py 300750 宁德时代 250
```

参数说明：

- **代码**（必填）：6 位代码，个股或场内 ETF（沪 60/68/51/56/58，深 00/30/15/16/18）。
- **名称**（可选）：提升精度，可省略。
- **天数**（可选，默认 120，上限 250）：日 K 根数。筹码分布用「时间衰减」，建议 ≥ 120（半衰期 40 日，120 日覆盖约 3 个半衰期）。

脚本输出 6 段数据包：**① 基本信息** → **② 技术位与箱体阶段** → **③ 支撑/压力位明细** → **④ 筹码分布** → **⑤ 自适应网格** → **⑥ 是否适合网格**。

## 分析框架（AI 在数据包之上生成报告）

严格按以下 6 段组织输出：

### 一、标的画像
从「①」提炼：个股还是 ETF、最新价与涨跌幅、数据来源（本地库·成交额 还是 新浪·成交量，后者筹码分布为近似）。一句话说清「什么标的、现在什么价」。

### 二、趋势阶段（关键结论放句首）
从「②」判断，用「关键结论：xxx」开头。箱体阶段四档：**强箱体震荡 / 箱体震荡（偏中性）/ 弱箱体·方向未明 / 趋势市（不利网格）**。逐条列脚本给出的 reasons，并标注现价在箱体的位置百分位（0% 下沿 / 100% 上沿）——**位置决定网格是双向还是单向**（贴近边沿时一侧无档可做）。

### 三、支撑/压力与筹码结构
从「③④」解读：
- **支撑压力位**：摆动低点/摆动高点（被反复测试的转折点）、枢轴 S/R（由前一日 H/L/C 套公式，偏弱）、成交密集区（大量换手区）。
- **筹码分布**（④）：获利盘比例、平均成本、90%/70% 成本区间、筹码峰。关键判断：
  - **获利盘 20%~80%** 多空均衡；**>80%** 上方获利了结压力、易冲高回落；**<20%** 上方套牢盘重、反弹遇阻。
  - **现价贴近平均成本**（偏差 ≤5%）多空均衡、易震荡，最适合网格；远离成本则偏趋势。

### 四、自适应网格如何用（核心）
从「⑤」解读网格线。每条线 = 一个价位 + 方向（买=现价下方支撑档 / 卖=现价上方压力档）+ 强度（强/中/弱）+ 来源：
- **来源是几何类型**，方向由「相对现价位置」决定：**摆动高点跌破后是支撑、摆动低点涨破后是压力**；「·」= 多来源共振（强度累加，越强越可信）。
- **买档**：现价跌到该档位分批买入；**卖档**：现价涨到该档位分批卖出。强弱决定该档仓位轻重。
- **对照传统等距网格**（⑤末尾）：说明非等距网格把档位压在了真实支撑压力上，而非机械均分——**等距网格在密集支撑区可能买太少、在无支撑区买太早**。
- 若「⑤」无网格线：现价上下方没有足够的支撑/压力/筹码峰，说明该标的当前技术位稀疏，不宜机械做网格。

### 五、是否适合网格（结论 + 依据）
以「⑥」的结论为准（✅适合 ≥70 / ⚠️观望 50~69 / ❌不适合 <50），逐条列 reasons。注意**箱体阶段是闸门**：趋势市最多「不适合」、弱箱体最多「观望」，非明确箱体不给「适合」。即使结论是「不适合」，网格线仍可用于**分批低吸/高抛参考**（趋势市里下方支撑档是回调加仓位、上方压力档是减仓位），要讲清这个区别。

### 六、风险提示（每次必带）
- 网格是**区间纪律**，不是「稳赚」：单边趋势/破网会放大亏损；下方买档跌破后要止损而非无限补仓。
- **筹码分布是「成交额×时间衰减」的近似**（东财筹码接口被 IP 封锁、无真实获利盘数据），获利盘比例/成本区间是量价推导，非交易所口径，仅作参考。
- 以上是公开行情/技术指标的量化分析，不构成投资建议，请独立决策并控制仓位。

## 注意事项

- **数据源**：本地 DuckDB（前复权日K + 成交额，主源，仅覆盖 A 股 5573 只）→ 新浪日K（ETF/缺库兜底，只有成交量，筹码分布退化为成交量近似）→ 新浪实时行情（现价）。**不依赖 `MX_APIKEY`**。
- **筹码分布口径**：成交额（个股）/ 成交量（ETF）× 时间衰减（半衰期 40 交易日）→ 三角分布摊到日 [low, high]，算获利盘比例/平均成本/90%·70%成本区间/筹码峰。这是标准「成本分布」的简化版，**非交易所真实筹码**，别在报告里说成「官方筹码数据」。
- **网格线来源语义**：方向由现价位置定，不随来源的「支撑/压力」字面走——一个「摆动高点」在现价下方时它就是支撑（前高被突破）。读档位时先看「方向」，再看「来源」。
- **强度口径**：强 = 多来源共振或最高筹码峰，中 = 单一摆动位/次高筹码峰，弱 = 单一枢轴位/成交密集区。弱档仓位宜轻、可做减仓参考而非主买点。
- **个股 vs ETF**：ETF 无个股黑天鹅、单边破网风险相对小，但行业/主题 ETF 有板块性下杀；个股还要留意基本面暴雷（可补跑 stock-analysis / news-search）。
- **不臆造**：脚本没查到的（基本面、资金流、机构持仓）不要编造，需要时叠加对应 skill 补查。
