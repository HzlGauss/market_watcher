# ETF 网格交易分析

查询某只场内 ETF 的实时行情与日 K 线，诊断是否箱体震荡、是否适合网格，并给出网格参数参考。

## 用法

```bash
py .claude/skills/etf-grid/analyze_etf_grid.py <代码> [名称] [天数]
```

示例：

```bash
py .claude/skills/etf-grid/analyze_etf_grid.py 510300 沪深300ETF
py .claude/skills/etf-grid/analyze_etf_grid.py 159915 创业板ETF 120
py .claude/skills/etf-grid/analyze_etf_grid.py 512880          # 不带名称，默认拉60日
```

参数说明：

- **代码**（必填）：6 位场内 ETF 代码（沪 51/56/58，深 15/16/18 开头）。
- **名称**（可选）：提升精度，可省略。
- **天数**（可选，默认 60）：拉取的日 K 线根数，上限 120。网格判断建议 ≥ 60，太短箱体不可靠。

脚本输出 6 段数据包：**① 基本信息**（最新价/涨跌幅/振幅/成交额）→ **② 技术位**（MA5/10/20/60、均线排列、各周期高低点、区间涨跌幅）→ **③ 箱体与波动率诊断**（箱体区间、位置百分位、ATR%、日振幅、波动率、布林带宽、趋势斜率、箱体震荡评分）→ **④ 支撑阻力** → **⑤ 网格参数参考** → **⑥ 近期 K 线**。

## 分析框架（AI 在数据包之上生成报告）

严格按以下 6 段组织输出：

### 一、标的画像
从「①」+ 名称提炼：跟踪什么指数/板块、宽基还是行业/主题 ETF、最新价与涨跌幅。一句话说清它「跟什么、现在什么位置」。

### 二、是否处于箱体震荡阶段（关键结论放句首）
从「②③」判断趋势阶段，用「关键结论：xxx」开头。依据：
- **均线排列**（②）：缠绕 = 震荡；多头/空头排列 = 趋势市（不利网格）。
- **区间涨跌幅**（②）：近 60 日涨跌幅越小越像震荡；> ±20% 是单边趋势。
- **趋势斜率**（③）：%/日 接近 0 是走平；明显正/负是趋势。
- **箱体震荡评分**（③）：强箱体震荡 / 箱体震荡 / 弱箱体 / 趋势市，逐条列脚本给出的 reasons。
- 标注箱体上沿/下沿与当前价所在位置（③的位置百分位）。

### 三、当前价是否适合买入（表格 + 一句话结论）
结合「③箱体位置百分位」判断现价在箱体的**上沿/中部/下沿**：
- 下沿附近（< 33%）：适合分批/网格开仓，赔率好。
- 中部（33%~67%）：中性，可半仓试探。
- 上沿附近（> 67%）：不适合追高，等回踩或网格减仓。
- 结合 RSI（③）看是否超买/超卖。给一句话结论。

### 四、是否适合自动网格交易（结论 + 依据）
网格的三个前提，逐条对照脚本数据给出 ✅/⚠️/❌：
1. **箱体震荡**（有明确上下沿、非单边趋势）——看「②③」。
2. **波动率合适**（ATR%/平均日振幅能覆盖成本且不过大）——ETF 单边佣金约万 0.5~万 1.5，双边约 0.02%~0.06%，无印花税；**日振幅 ≥ 1% 才够吃价差，> 4% 则波动过烈、破位风险大**（③）。
3. **非趋势市**（均线不单边、区间涨跌幅不过大、趋势斜率近 0）。
综合给出**适合 / 观望 / 不适合**，并说明主要风险（如：ETF 虽无个股黑天鹅，但行业/主题 ETF 若遇板块单边下杀同样会破网套牢）。

### 五、网格如何设置（若适合；不适合则给「等待条件」）
以「⑤」的参考值为基础微调，给出表格：

| 参数 | 设置 | 逻辑 |
|---|---|---|
| 网格区间 | 下沿 ~ 上沿 | 用近 60 日高低点，参考支撑/阻力 |
| 网格间距 | x 元（约 x%） | 按 ATR% 自适应，夹 1.2%~3% |
| 格数 | n 档 | 区间 ÷ 间距 |
| 首仓/底仓 | x% | 依现价在箱体位置（下沿多买、上沿少买） |
| 破网止损 | 收盘跌破 x | 下沿下方一档 |

**破网处理**单独写：向下破网（收盘跌破下沿）→ 停止加仓、网格暂停；深止损线（下沿下方再一档）→ 清仓；向上破网 → 卖完仓后不追高。
**成本校验**单独一行：单格价差须 ≫ 双边佣金（约 0.02%~0.06%），否则网格白忙。

### 六、免责声明（每次必带）
固定加一句：以上是基于公开行情/技术指标的量化分析，不构成投资建议；网格交易在单边下跌中会放大亏损，行业/主题 ETF 有板块性风险，请独立决策并控制仓位。

## 注意事项

- **数据源**：新浪财经（实时行情 + 日K线，主源）+ AKShare（K线兜底）+ 妙想（名称兜底）。**不依赖 `MX_APIKEY`**，无 key 也能跑（名称可能为空，用代码识别即可）。
- **ETF 代码校验**：非 51/56/58/15/16/18 开头的代码会提示「疑似非 ETF」，仍继续分析，请自行确认。
- **箱体震荡评分是倾向性指标**，非绝对：评分 ≥ 5 强箱体、≥ 3 箱体、1~2 弱箱体、≤ 0 趋势市。AI 需结合均线排列、区间涨跌幅、趋势斜率综合判断，不能只看评分。
- **波动率与成本**：ETF 无印花税，网格成本主要为佣金，务必做「单格价差 vs 双边成本」校验；场内 ETF 常有最低 5 元佣金，小资金时按单笔金额折算实际费率。
- **不臆造**：脚本没查到的数据（规模、跟踪误差、份额申赎等）不要编造，需要时可补查。
- **预测是概率判断，不是保证**：网格给的是区间与纪律，避免「必涨/必跌」「稳赚」的绝对表述。
