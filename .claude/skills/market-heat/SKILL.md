# 市场热度雷达（market-heat）

拉取**涨幅榜 + 跌幅榜 + 龙虎榜**，聚合个股行业与板块资金流，输出**热点方向 / 避坑方向 / 情绪周期**数据包。脚本只取数算聚合，「热点 / 避坑」结论由 AI 依据下方框架生成。

与其他 skill 的分工：
- `dragon-pullback`（龙回头）= 单只龙头股缩量回调二次启动，短线博弈；
- `golden-pit`（黄金坑）= 单只白马深坑缩量企稳，价值/波段；
- `sector-flow` = 单一板块资金流排名；
- **本 skill** = 全市场视角，回答「资金正在往哪个方向走、该关注什么、该回避什么」。

## 用法

```bash
py .claude/skills/market-heat/scan_market_heat.py [涨幅榜数量] [跌幅榜数量]
```

示例：

```bash
py .claude/skills/market-heat/scan_market_heat.py          # 涨幅榜/跌幅榜各 20
py .claude/skills/market-heat/scan_market_heat.py 30 20    # 涨幅榜 30、跌幅榜 20
```

脚本输出 **7 段数据包**：

- **【1. 涨幅榜】**：全市场涨幅前 N（代码/名称/涨跌幅/成交额/换手率/市值/行业）
- **【2. 跌幅榜】**：全市场跌幅前 N（同上）
- **【3. 龙虎榜资金】**：净买入 top 10 + 净卖出 top 10（代码/名称/净买入额/涨跌幅/行业/上榜原因）
- **【4. 热点方向聚合】**：涨幅榜 + 龙虎榜净买入 的**行业聚集计数**（哪个行业上榜最多）
- **【5. 避坑方向聚合】**：跌幅榜 + 龙虎榜净卖出 的**行业聚集计数**
- **【6. 板块资金流佐证】**：概念板块 + 行业板块 今日主力净流入 top / 净流出 top（含领涨/领跌股）
- **【7. 情绪面】**：涨跌家数、涨停/跌停家数（9.9% 近似）、龙虎榜净买/净卖额对比

## 分析框架（AI 在数据包之上生成报告）

严格按以下 4 段组织输出。

### 一、热点方向（【1】+【3】+【4】+【6】概念）
- **三者共振 = 主线**：行业聚集靠前 + 概念板块净流入靠前 + 龙虎榜净买入，三个维度指向同一方向，才是真正的当前主线（如「电子行业聚集 + AI算力概念净流入第一 + 龙虎榜净买入集中在算力股」）。
- **单一维度信号 = 轮动/脉冲**：只有涨幅榜有、但无资金流/龙虎榜确认，说明是脉冲行情或一日游，追高须谨慎。
- **结论放句首**：如「当前主线是 AI 算力（电子行业聚集 + 概念净流入第一 + 龙虎榜净买入共振）」。

### 二、避坑方向（【2】+【3】+【5】+【6】概念净流出）
- **跌幅榜行业聚集 + 概念板块净流出 + 龙虎榜净卖出** = 资金正在撤离的方向，警惕退潮。
- **区分两种跌**：①「涨多了回调」——涨幅榜前期热点短期获利了结，逻辑未坏，可能还有第二波；②「逻辑走坏」——龙虎榜持续净卖出 + 概念资金持续净流出 + 基本面料恶化，是真退潮，回避。
- **结论放句首**：如「当前退潮方向是新能源（跌幅榜聚集 + 概念净流出 + 龙虎榜净卖出）」。

### 三、情绪周期（【7】）
- **涨停家数 vs 跌停家数**：涨停远多于跌停 = 亢奋/进攻期；跌停明显增多 = 冰点/恐慌期；两者接近 = 震荡/分歧。
- **龙虎榜净买 vs 净卖**：净买额远超净卖额 = 资金进场意愿强；净卖额放大 = 资金避险。
- **判断处于什么阶段**：情绪亢奋时热点易扩散但波动大；情绪冰点时往往是情绪拐点前的低吸区（需结合基本面确认）。

### 四、结论（一句话 + 免责声明）
先给**一句话结论**（当前热点方向是什么 / 该回避什么方向 / 情绪处于什么阶段），再给操作提示（热点可关注但不追高、退潮方向回避、情绪冰点观察拐点）。

**免责声明**（每次必带）：以上基于公开行情/资金流/龙虎榜数据分析，不构成投资建议；热点可能一日游，追高须设好止损、独立决策。

## 注意事项

- **数据源**：全市场行情 + 行业（东财 clist，直连 `_fetch_em_clist`，不依赖 akshare `stock_zh_a_spot_em` 易断连接口）、龙虎榜（`app.dragon_tiger`）、板块资金流（东财数据中心）。**全部不依赖 `MX_APIKEY`**。
- **非交易时段**：显示最近收盘数据；龙虎榜为最近交易日（节假日顺延）。
- **涨停阈值近似**：9.9% 近似统计，含创业板/科创板 20cm，ST 股 5% 涨停不计入。
- **行业 ≠ 概念**：行业板块（电子/计算机）较宽泛，概念板块（AI算力/机器人）更贴合主题炒作；本 skill 用「行业聚集 + 概念板块资金流」两条腿交叉，比单一维度更准。
- **概念板块噪音**：东财「概念板块」资金流里混有「融资融券 / MSCI中国 / 富时罗素 / 科技风格」等指数/风格类条目，覆盖股票多、净流入流出额天然巨大，会占据榜单前列。分析热点/避坑时须**忽略这类非主题条目**，只看真正的题材概念。
- **不臆造**：脚本没查到的（具体消息、题材催化剂）不要编造；需要时叠加 `/news-search` 查热点板块的消息面、`/fund-flow` 查具体个股资金、`/dragon-pullback` 查涨停股是否构成龙回头。
- **热点轮动快**：单日榜单反映的是「当下」，不代表「可持续」；判断主线要看多日延续性（可结合 `sector-flow` 的 5 日/10 日资金流看趋势）。
