# 大盘盯盘（market-watch）

拉取 **8 大指数行情 + 市场广度 + 板块资金流 + 两融余额**，输出大盘研判数据包。脚本只取数算聚合，「大盘强弱 / 进攻防守」结论由 AI 依据下方框架生成。

与其他 skill 的分工：
- `market-heat` = 全市场静态热度雷达（涨幅榜/跌幅榜/龙虎榜 → 热点/避坑方向），偏盘后方向归纳；
- `sector-flow` = 单一板块资金流排名；
- `limit-analysis` = 涨跌停深度分析（涨停梯队/炸板率/封单/题材），短线情绪周期；
- **本 skill** = 盘中大盘视角，回答「今天大盘强不强、该进攻还是防守」。

## 用法

```bash
py .claude/skills/market-watch/scan_market_watch.py
```

脚本输出 **5 段数据包**：

- **【1. 核心指数】**：8 大指数现价/涨跌幅/成交额/近 60 日位置百分位/均线排列（上证/深证/创业板/创业板50/科创50/沪深300/中证500/中证1000）
- **【2. 量能分析】**：各指数「今日/5日均量」倍数 + 放量/温和/缩量标签 + 近5日量能趋势 + 全市场放缩量家数汇总
- **【3. 市场广度】**：涨跌家数（含上涨占比）、涨停/跌停家数（9.9% 近似）、全市场成交额
- **【4. 板块资金流】**：行业/概念板块今日主力净流入 top + 净流出 top + 全市场主力净流入合计
- **【5. 两融余额】**：融资/融券/两融总余额 + 融资净买入方向（**替代已停披露的北向资金**）

## 分析框架（AI 在数据包之上生成报告）

### 一、指数多空与量能（【1】+【2】）
- **谁领涨谁领跌**：大小盘/成长价值哪边强（上证/沪深300=权重，创业板/科创50/中证1000=成长小盘）。权重强而小盘弱=防御；小盘强而权重弱=进攻。
- **均线排列**：多数指数多头排列=趋势向上；空头排列=趋势向下；缠绕=震荡。
- **量能健康度**（核心，结合【2】量能分析 + 【3】全市场成交额）：看多数指数是放量还是缩量、放量在涨还是跌的方向——**放量上涨=真突破（健康）**、**缩量上涨=动能不足（乏力）**、**放量下跌=恐慌/出货**、**缩量下跌=抛压减轻（磨底）**。全市场放量指数远多于缩量=资金活跃；缩量居多=观望/清淡。近5日量能趋势（放量趋势/缩量趋势）判断量能是扩张还是衰减。

### 二、广度与情绪（【3】）
- **上涨占比**：>70% = 普涨进攻；<30% = 普跌防守；40~60% = 分化震荡。
- **涨跌停家数**：涨停远多于跌停=情绪偏暖；跌停明显增多=情绪偏冷。精确涨停梯队看 `/limit-analysis`。

### 三、资金方向（【4】+【5】）
- **板块净流入**：主力净流入集中方向 = 今天钱在买什么；净流出集中 = 钱在撤离什么。行业与概念两条腿交叉验证。
- **两融**：融资余额环比上升 + 融资净买入为正 = 杠杆资金加仓（看多）；反之减仓。这是**替代北向资金**的杠杆资金温度计（北向实时净流入已停止披露）。

### 四、结论（一句话 + 操作提示）
先给**一句话结论**（今天大盘强弱定性 + 该进攻还是防守），再给操作提示（强→可参与热点、弱→降仓防守/观望、震荡→控制仓位做 T）。

**免责声明**（每次必带）：以上基于公开行情/资金流/两融数据分析，不构成投资建议；独立决策。

## 注意事项

- **数据源**：指数行情+K线（新浪）、全市场广度（东财 clist）、板块资金流（东财数据中心）、两融（akshare `stock_margin_sse`/`stock_margin_szse`）。**全部不依赖 `MX_APIKEY`**。
- **北向资金已停披露**：2024年8月起交易所停止披露北向实时净买入额，本 skill 用**两融余额**替代，勿再引用「北向净流入」。
- **非交易时段**：显示最近收盘数据。
- **涨停阈值近似**：市场广度段的涨停/跌停用 9.9% 近似（含 20cm、ST 5% 不计入）；精确梯队走 `/limit-analysis`。
- **全市场主力净流入为近似**：由行业板块资金流求和得出，非逐股精确统计，仅作方向参考。
- **概念板块噪音**：东财「概念板块」资金流里混有「融资融券 / MSCI中国 / 深股通 / 沪股通 / 富时罗素」等指数/风格类条目，覆盖股票多、净流入流出额天然巨大，会占据榜单前列。分析领涨领跌时须**忽略这类非主题条目**，只看真正的题材概念（这也是概念段不输出「合计」的原因）。
- **不臆造**：脚本没查到的（具体消息、催化剂）不要编造；需要时叠加 `/news-search` 查消息面、`/market-heat` 看热点方向。
