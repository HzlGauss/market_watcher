# 黄金坑检测（golden-pit）

对白马股/蓝筹股做「黄金坑」检测：**基本面扎实的股票被市场恐慌或短期利空错杀，价格深度挖坑（回撤 20%~45%）后缩量企稳，赌其估值修复**。脚本只取数算指标，输出 6 段数据包；「是否构成黄金坑 / 能否参与 / 买点与止损」由 AI 依据下方框架生成。

与 `dragon-pullback`（龙头 + 连板 + 动量的短线博弈）不同，黄金坑是**价值/波段**逻辑：标的本身是白马蓝筹，靠「基本面未坏 + 深度错杀 + 缩量企稳」取胜。

## 用法

```bash
py .claude/skills/golden-pit/analyze_golden_pit.py <代码> [名称] [天数]
```

示例：

```bash
py .claude/skills/golden-pit/analyze_golden_pit.py 600519 贵州茅台
py .claude/skills/golden-pit/analyze_golden_pit.py 000858 五粮液 250
```

参数说明：

- **代码**（必填）：6 位 A 股代码（个股）。
- **名称**（可选）：提升妙想查询精度，可省略。
- **天数**（可选，默认 250，上限 400）：拉取的日 K 线根数。≥120 才能算 MA120（半年线），250 才算 MA250（年线）。黄金坑需覆盖「高点→挖坑→企稳」完整过程，建议用默认 250。

### 批量扫描（找候选）

不确定看哪只时，先用批量版从白马/蓝筹指数成分股里筛出潜在黄金坑候选：

```bash
py .claude/skills/golden-pit/scan_golden_pit.py [输出数量]
```

示例：`py .claude/skills/golden-pit/scan_golden_pit.py 20`（输出 top 20）。

批量版流程：拉沪深300 ∪ 上证50 ∪ 中证红利成分股（天然白马蓝筹池）→ 逐股拉 250 根日K线跑六层检测打分 → 硬门槛筛掉「未明显回调 / 已破位走坏 / 放量下跌」→ 按信号分排序输出候选表 → 对 top 候选做妙想基本面快查（估值分位/ROE/股息率）。**回撤 >45% 的深坑股不直接丢弃**，而是标记「❌ 深度超阈值」单独列一张表（按「站半年线 / 缩量」排序，供人工判断是「深度错杀」还是「暴雷」）。**候选池用 akshare 指数成分（`index_stock_cons`），K 线走新浪，核心不依赖 `MX_APIKEY`**；约 2~4 分钟（约 400 只成分股逐股拉 K 线）。批量版是初筛，确认单只估值/买点/止损时再用上面的单股版细看。

脚本输出 **6 段数据包**：

- **① 白马成色**：板块（主板/创业/科创）+ **指数成分归属**（是否沪深300/上证50/中证红利成分，作为「白马蓝筹」的代理证据）
- **② 挖坑幅度**：坑沿高点（日期+价）→ 现价、**现价回撤%**、坑底最低点、最深回撤、距高点交易日数、深度分级
- **③ 坑底缩量**：坑段（高点之后）均量 vs 高点前 20 日均量、**缩量比**（<0.6 抛压衰竭 / ≥1.0 放量下跌）
- **④ 估值低位 + 基本面**：妙想 PE/PB 历史分位、股息率、ROE、营收/净利同比、负债率 + 抽取关键数字（PB三年分位/PE/PB/净利同比/营收同比/ROE）
- **⑤ 企稳反转**：是否站上 MA20/MA60、RSI 位置、MACD 金叉/多头、KDJ 金叉、止跌 K 线形态（长下影/锤子/看涨吞没）
- **⑥ 结论聚合**：长期趋势（MA120 半年线 / MA250 年线是否站上）+ 技术 checklist（6 项）+ **基本面/估值确定性门槛 checklist**（净利同比≥0 / PB分位≤70 / ROE≥8）+ **信号分级**（✅/⚠️/❌，技术面全过后叠加基本面否决）+ 参考关键位（坑沿高点/坑底低点/MA20/60/120/250/技术支撑压力）

## 分析框架（AI 在数据包之上生成报告）

严格按以下 7 段组织输出。**核心：先判「是不是白马、挖没挖坑」，再判「坑健不健康、缩没缩量」，最后判「能不能买、买点止损」。**

### 一、是不是白马/蓝筹（【1】+【4】）
先给**一句话结论**（是不是基本面扎实的白马/蓝筹，及依据）：
- **指数成分**：在沪深300/上证50/中证红利里 = 白马蓝筹的强代理；都不在则看【4】基本面是否达标（高 ROE、稳定盈利、大市值）。
- **基本面**（【4】）：ROE 常年 >15%、营收/净利正增长、负债率适中、稳定分红 = 白马成色足；若净利大幅下滑/亏损 = 不是「错杀」而是「基本面恶化」，直接降级。
- **这是黄金坑的绝对前提**：基本面坏了就谈不上「坑」，那叫「跌」。

### 二、挖坑够不够深（【2】）
- **幅度**：现价回撤落在 **20%~35%** 最理想（风险充分释放、又未破位）；35%~45% 是深坑（错杀嫌疑大，但必须警惕基本面是否恶化）；<20% 只是普通回调、不构成黄金坑；**>45% 为「深度超阈值」**——默认按趋势性下跌/暴雷对待，但不直接丢弃，须结合【4】基本面确认是「深度错杀」还是「暴雷」（批量版会单独列出这类候选）。
- **时间**：坑应有一定时间跨度（距高点 ≥ 一个多月较健康），过快下跌（连续跌停式）往往是利空而非错杀。
- **关键结论放句首**：如「现价回撤 28%、距高点 45 日，标准黄金坑深度」。

### 三、坑底缩没缩量（【3】，核心）
这是区分「错杀」（缩量）与「出货/暴雷」（放量）的关键：
- **缩量**：坑段均量 < 高点前 0.7 倍 = 抛压衰竭、筹码锁定（✅ 健康挖坑）。
- **放量**：坑段均量 ≥ 高点前量 = 有资金持续出逃/利空发酵，直接弃。
- **量价背离**：价格新低但成交量明显萎缩 = 底部特征，加分。

### 四、估值够不够低（【4】，确定性门槛）
- **PE/PB 历史分位**：分位越低越好（<30% 较安全，<10% 是显著低估）；分位仍高 = 只是「贵了回落」，安全垫不足。**PB 历史分位 >70% 会被脚本判 ⚠️ 高位，属确定性门槛，非仅参考。**
- **股息率**：白马蓝筹若股息率 >4%~5%，提供硬底支撑。
- **ROE/盈利**：确认基本面未恶化是「错杀」的证据。**净利同比 <0 会被脚本判 ❌ 真跌（基本面恶化，排除）；ROE <8% 判 ⚠️ 白马成色不足。** 盈利下滑 + 低估值 = 可能是价值陷阱，须谨慎。

### 五、企稳了没有（【5】）
- **站上 MA20/MA60**：坑底走出、站回中短期均线 = 修复启动信号。
- **RSI/MACD/KDJ**：RSI 从超卖（<30）回升、MACD 金叉/柱转正、KDJ 金叉 = 反转信号；超卖但未见底 = 可能还有惯性下杀，别接飞刀。
- **止跌 K 线形态**（长下影/锤子/看涨吞没）+ 缩量 = 左侧埋伏可观察信号。

### 六、未破长期趋势（【6】+ 关键位）
- **年线 MA250 / 半年线 MA120**：站上 = 长期趋势未坏（黄金坑的典型形态）；跌破半年线 = 长期趋势走坏，属「趋势性下跌」而非「坑」，弃。
- **买点参考**：坑底低点上方企稳区是左侧埋伏区；站上 MA20 + MACD 金叉 + 放量 = 右侧确认买点。
- **止损**：跌破**坑底低点**（近期最低）或**半年线 MA120** 即止损，收盘确认；黄金坑失败 = 补跌，纪律性离场。

### 七、结论（表格 + 一句话）
先给**一句话结论**（✅ 可参与 / ⚠️ 观察等待 / ❌ 放弃），严格遵循脚本【6】的信号分级方向。**基本面/估值已是脚本内置的确定性门槛**（技术面全过后自动叠加否决），AI 不得把脚本判 ❌/⚠️ 的写成「可参与」：

| 情形 | 结论 |
|---|---|
| ✅ 技术形态全过 + 净利同比≥0 + PB分位≤70 + ROE≥8 | 可参与，给买点与止损 |
| ⚠️ 形态接近但缩量不明显 / 缺企稳确认 / PB分位>70 / ROE<8 | 观察等待，说明等什么信号转可参与 |
| ❌ 非白马 / 净利同比<0 / 回撤过浅或过深 / 放量下跌 / 破半年线 | 放弃，复述原因 |

**确定性门槛优先级**（脚本【6】在技术面全过时按序否决）：净利同比<0 → ❌ 真跌；PB分位>70 → ⚠️ 估值高；ROE<8 → ⚠️ 成色弱；**PB分位缺失 → ⚠️ 待查（不放行 ✅）**；三者都过 → ✅ 构成黄金坑。缺妙想数据时脚本只报技术形态，AI 须提示「未查估值/基本面，确认后再参与」。

**免责声明**（每次必带）：以上是基于公开行情/基本面/技术指标的分析，不构成投资建议；黄金坑是价值/波段判断，需确认基本面未恶化、设好止损、独立决策。

## 注意事项

- **数据源**：实时快照（新浪）、日 K 线（新浪，AKShare 兜底）、指数成分（AKShare `index_stock_cons`）、基本面+估值（妙想，需 `MX_APIKEY`）。**技术面核心不依赖 `MX_APIKEY`**；缺妙想 key 时【4】估值/基本面显示「跳过」，但【1】【2】【3】【5】【6】仍可用。
- **「错杀」与「真跌」的分野是本 skill 的灵魂**：脚本只算技术形态，是否「错杀」必须靠【4】基本面+估值确认——ROE 仍高、盈利未大幅下滑、估值历史低分位，三者支撑「错杀」结论；缺一则警惕价值陷阱。
- **指数成分 ≠ 全部白马**：不在三只指数里的股票也可能是白马，须由【4】基本面独立判断；反之，成分股里也可能有基本面走坏者。
- **不臆造**：脚本没查到的（具体利空事件、机构持仓变动）不要编造；需要时叠加 `/news-search` 查利空/减持/解禁、`/fund-flow` 查近期主力资金是否回流、`/sector-flow` 看所属板块是否企稳。
- **预测是概率判断**：黄金坑可能继续深挖（磨底时间不可测），始终给关键位与触发条件，避免「必涨/必反弹」的绝对表述；左侧埋伏需分批、留足补仓空间。
