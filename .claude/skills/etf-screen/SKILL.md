# 全市场 ETF 多维度筛选（etf-screen）

从全市场 ETF 中按四维打分筛出候选：**流动性+规模（硬门槛）→ 动量+趋势 → 估值分位 → 资金流+份额**。借鉴「AI量化+ETF」研报的动量/景气度/资金流三信号择时思想，落到可执行的 ETF 筛选上。

## 用法

运行打包脚本，传入可选类型/关键词和输出数量：

```bash
py .claude/skills/etf-screen/screen_etf.py [类型|关键词] [输出数量]
```

示例：

```bash
py .claude/skills/etf-screen/screen_etf.py                 # 全市场 ETF 筛选
py .claude/skills/etf-screen/screen_etf.py 半导体          # 只筛半导体方向
py .claude/skills/etf-screen/screen_etf.py 沪深300 10      # 宽基沪深300，输出前10
py .claude/skills/etf-screen/screen_etf.py 债券 8          # 只筛债券类
py .claude/skills/etf-screen/screen_etf.py 宽基            # 只筛宽基指数 ETF
```

参数说明：

- **类型|关键词**（可选，默认全市场）：
  - **类型**：`宽基` / `行业` / `主题` / `债券` / `跨境` / `商品` / `货币`
  - **具体跟踪方向**：`半导体` / `医药` / `新能源` / `券商` / `沪深300` / `中证500` / `恒生` / `黄金` / `纳指` ...（名称/跟踪方向模糊匹配）
- **输出数量**（可选，默认 15）：候选数量上限。

约 1~2 分钟（拉 60 只 ETF 的日 K 线）；若配置了 `MX_APIKEY`，还会对 top 候选查估值分位 + 净申购额（更慢，约再 +1~2 分钟）。

## 四维打分设计

| 维度 | 数据源 | 处理 | 分值 |
|---|---|---|---|
| 流动性+规模 | 免费层（东财快照） | **硬门槛**：成交额 ≥ 1000万、规模 ≥ 2亿，不达标直接剔除 | — |
| 动量+趋势 | 免费层 | 近20日涨幅 + 均线排列 + MACD + RSI 位置（偏「追势」） | 0~40 |
| 估值分位 | key 层（妙想） | 跟踪指数 PE/PB 历史分位，分位越低分越高 | 0~30 |
| 资金流+份额 | 免费+key | 主力净占比（免费，0~10）+ 净申购额（妙想申赎口径，0~20） | 0~30 |

综合分 = 动量 + 估值 + 资金流 = 满分 100，按综合分降序输出。缺 `MX_APIKEY` 时只出免费层（动量 + 主力净占比），估值/净申购列标「待补」。

## 脚本输出与解读

表格列：代码 | 名称 | 类型 | 现价 | 涨跌幅 | 成交额(亿) | 规模(亿) | 跟踪方向 | 动量分 | 估值分位 | 主力净占比 | 净申购(亿) | 综合分

- 金额单位**亿元**；`待补` = 该 key 层字段因无 key 或指数名未被识别而缺失。
- 动量分偏「追势」——已走强的标的分高，与 `left-side`（超跌埋伏）互为镜像；要做「跌出来买」请走 `left-side`/`etf-grid`。

## 分析框架（AI 在候选表之上生成报告）

1. **先给结论**：当前市场里值得关注的 ETF 方向有哪些、整体资金/估值位置如何；候选为 0 说明该方向当前无流动性/规模达标且动量靠前的标的。
2. **解读 top 候选**：讲清每只的动量（涨幅/均线/MACD/RSI）、估值分位（低=安全垫高）、资金流（主力是否流入 + 是否净申购）三者是否共振。
3. **估值 + 资金流缺一不可轻信**：估值分位「待补」或净申购「待补」时，只按动量下结论，并明确提示未验证。
4. **落到操作**：对确认候选给出「关注/分批/回避」倾向，并提示确认买点应叠加单只细看（`etf-grid` 网格、`stock-analysis` 诊基）。

## 注意事项

- **数据源**：免费层 `fund_etf_spot_em`（东财快照，全市场 1600+ 只一次拿全）+ 新浪 ETF K 线；key 层妙想（估值分位 + 净申购额，需 `MX_APIKEY`）。**免费层不依赖 key**。
- **分类/跟踪方向是短板**：类型与跟踪方向靠 ETF 名称推断（`_etf_name_to_industry` + 关键词），可能误判个别冷门 ETF；具体方向请用「名称/跟踪方向」子串再确认。
- **估值分位依赖指数名识别**：仅对宽基/部分行业 ETF 名称里能识别的跟踪指数（沪深300/中证500/半导体/医药/券商/军工等）有效，识别不到则该维度缺失。
- **不臆造**：脚本没查到的（具体折溢价率、申赎限额、跟踪误差、管理人）不要编造；需要时叠加 `/fund-flow` 查单只资金流、`etf-grid` 看箱体/网格、`stock-analysis` 做单只诊基。
- **镜像关系**：本 skill 是「追势/综合打分」的 ETF 初筛；要「超跌埋伏」走 `left-side`，要「箱体网格」走 `etf-grid`，要「单只深诊」走 `stock-analysis`。
