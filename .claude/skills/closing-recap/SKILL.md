# closing-recap — 收盘复盘 + 短期操作（重点持仓）

收盘后对 `holdings.csv` 里 `show_flow=1` 的标的（个股 + 场内 ETF）做**轻量复盘**：今日走势 + 技术阶段 + 主力资金方向，据此生成短期操作结论，并更新进 memory 的**合并单文件** `holdings-closing-recap.md`。

> 轻量版：不拉基本面/估值分位/研报/筹码。那些留给 `stock-analysis`（单只深挖）或 `financial-query`。这里只回答「今天怎么样 + 短期怎么办」。

## 用法

```bash
py .claude/skills/closing-recap/recap_holdings.py
```

**收盘后（≥15:00）跑**。脚本读 `holdings.csv` 里 `show_flow=1` 的标的，逐个打印紧凑复盘块 + 汇总表。

## 数据源（本地优先，妙想兜底）

| 字段 | 首选 | 兜底 | 说明 |
|---|---|---|---|
| 今日收盘价/涨跌幅 | `state/close_drift_latest.json`（`c1500` + `day_pct`，收盘竞价定盘价） | 本地资金流快照 → 妙想 | close_drift 命中即真收盘；回退到资金流快照时标注「·盘中」 |
| 今日主力净流入 | `data/fund_flow_intraday.duckdb` 最后一条（东财源） | 妙想 | **须落库到尾盘（≥14:45）才用本地**；否则东财反爬致部分标的中午停更、盘中累计失真，自动回退妙想全天口径 |
| 近5日累计 / 连续流入天数 | 妙想 | — | 本地无历史资金流（`push2his` 被 IP 封锁） |
| ETF 净申购额 | 妙想 | — | 可能为空（妙想未返回该字段，属正常） |
| 技术面（均线/RSI/MACD/KDJ/箱体/阶段） | 本地 `data/market.duckdb` 日K | 新浪 | `fetch_daily_local_first` |

个股主力 = 超大单 + 大单；ETF 主力 = 主力净流入（+ 净申购额，申赎口径）。

## 输出字段解读

- `收 价(+涨跌%)`：收盘价 + 当日涨跌幅；`·盘中` 表示该快照非收盘定盘。
- `多头排列/空头排列/多头回调`：均线方向。
- `支撑X/压力Y`：技术位。
- `箱体[lower,upper]现价X%`：现价在箱体中的位置（近 100% = 箱体高位，近 0% = 低位）。
- `阶段:...(...%) 趋势/量能/动量`：`detect_stage` 定位（启动期/主升浪/下跌期/震荡市…）。
- `资金: 今日主力 X亿·截至HH:MM`：主力净流入；`·截至` 标注本地快照落库时刻；无标注 = 妙想全天口径。
- `⚠️价涨主力出货 / 价跌主力吸筹`：量价背离提示。

## 生成短期操作结论（AI 分析框架）

对每个标的，结合三件事给结论：

1. **趋势阶段**（多头/空头/震荡 + 阶段）→ 该不该参与、顺还是逆。
2. **主力方向**（今日 + 近5日累计 + 连续流入/流出天数）→ 资金是否站在你这边。
3. **位置**（现价在箱体 / 支撑压力中的位置）→ 现在买赔率如何。

产出四要素：**结论**（持有 / 加 / 减 / 清 / 空仓观望 / 回踩埋伏 / 突破追）+ **关键价位**（买点 / 卖点 / 止损）+ **一句话理由** + **下一步触发信号**。

不套统一模板：周期股（如紫金）锚在商品价格（金价），成长股锚在业绩/估值，ETF 看指数/板块趋势 + 申赎。已有单只深挖 memory 的（[[zijin-mining-entry-tracking-2026-11-02]]、[[shengbang-analysis-2026-11-05]]、[[siwitewei-entry-tracking-2026-11-02]] 等）结论以那为准，这里只做「每日收盘快照 + 方向更新」。

## 写入 memory（合并单文件）

结果写入 `memory/holdings-closing-recap.md`（`name: holdings-closing-recap`，`type: project`）：

- **单文件**，按标的用 `## 代码 名称` 二级标题分节；每节保留「最新一条复盘 + 结论」，旧的覆盖更新（保留一条「历史」折叠即可）。
- 每节写：收盘价/涨跌幅、主力今日+近5日+连续天数、阶段、结论 + 价位 + 触发信号。
- 关联已有单只深挖 memory（`[[...]]`）。
- 更新 `MEMORY.md` 索引一行。
