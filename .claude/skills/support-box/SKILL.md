# 强支撑 + 箱体极低位 选股扫描（support-box）

对**指定板块/行业**做单一维度筛选：找出「现价已跌到近 60 日箱体的**极低位**，且**紧贴下方强支撑位**」的票。这是一个**纯技术维度**扫描器——只看「跌到位 + 有支撑」，不看基本面、不看缩量超卖企稳。

与其它 skill 的分工：

- **`left-side`**：左侧埋伏的六层检测（超跌→缩量→超卖→企稳→未破长期趋势 + 估值门槛），是「完整左侧机会」判断。
- **`support-box`（本 skill）**：只抽「箱体极低位 + 强支撑」这一层，**聚焦、更快、更纯粹**。它选出的票不一定满足 left-side 的全部条件（可能还在放量下跌、可能基本面差），但都满足「跌到箱底 + 有支撑」。
- **`stock-analysis`**：单股精确诊断（算精确支撑/压力位 + 箱体位置），适合对 support-box 的 top 候选做复核。

## 用法

```bash
py .claude/skills/support-box/scan_support_box.py <板块/行业> [输出数量] [--sync] [--full]
```

示例：

```bash
py .claude/skills/support-box/scan_support_box.py 半导体
py .claude/skills/support-box/scan_support_box.py 创业板 20
py .claude/skills/support-box/scan_support_box.py 沪深300 15
py .claude/skills/support-box/scan_support_box.py 化工
```

参数说明：

- **板块/行业**（必填）：支持三类输入——
  - **指数**：沪深300 / 中证500 / 中证1000 / 上证50 / 中证红利 / 科创50 / 创业板指
  - **板**：创业板 / 科创板（全板成分，非指数）
  - **行业/概念**：半导体 / 芯片 / 化工 / 白酒 / 光伏 / 新能源 / 医药 / 军工 ...
- **输出数量**（可选，默认 20）：输出候选数量上限。
- **`--sync`**（可选）：先增量同步本地 marketdb 到最新（可能触发下载，遇 429 限流会失败）。
- **`--full` / `--no-prescreen`**（可选）：跳过本地库 streaks 初筛，全池逐股拉新浪 K 线（更慢但召回最全）。

## 扫描流程

解析成分股池 → **（池 ≥40 只时）先用本地 marketdb streaks 初筛「连续下跌/缩量」缩小范围** → 逐股拉 250 根日 K 线 → 只跑「箱体极低位 + 强支撑」检测打分 → 硬门槛筛掉「箱体位置过高 / 距支撑太远 / 已深破支撑」→ 按分排序输出候选表。**成分股池用 app.board_pool，K 线走新浪，核心不依赖 `MX_APIKEY`**；初筛后通常更快。streaks 初筛按本地库快照（可能落后最近交易日，脚本会提示），最终打分仍逐股用新浪实时复核，故初筛只减请求、不改变单股结论。

## 检测逻辑（单一维度，三个子项）

1. **箱体极低位**：用 `detect_box_regime` 算近 60 日箱体 [下沿, 上沿] 与现价位置百分位 `pos_pct`（0%=箱底 / 100%=箱顶）。**`pos_pct ≤ 25%`** 才算箱体极低位（硬门槛），越低越好。
2. **到达强支撑**：用 `calc_support_resistance` 取支撑位，只保留「强支撑」来源——**摆动低点（被反复测试的转折点）+ 成交密集区（大量换手的真实筹码区）**，找现价下方**最近的支撑位**，算距离 `dist_pct = (现价 - 最近支撑) / 现价`。**`dist_pct ≤ 8%` 且 `≥ -5%`** 才算「紧贴支撑且未深破」（硬门槛）。**刻意排除两类伪支撑**：箱体下沿（现价≈60日低，与「箱体极低位」高度共线）、枢轴点 S1/S2/S3（由前一日 H/L/C 套公式得出，S1 恒略低于前低，非被测试过的强支撑），否则「贴近支撑」对任何低位股都≈0、失去区分度。
3. **支撑密集度（强支撑）**：统计现价下方支撑位**数量**，数量越多 = 多重支撑共振 = 越强（加分项）。

### 评分（0~100）

- 箱体极低位 **50 分**：`pos_pct` 越低越高分（≤5% 满 50 分 → 20~25% 只 30 分）
- 贴近支撑 **30 分**：`dist_pct` 越小越高分（≤2% 满 30 分 → 6~8% 只 15 分）
- 支撑密集度 **20 分**：下方 ≥3 个支撑 20 分、2 个 14 分、1 个 8 分

分级：**✅ 强(≥85) / ⚠️ 中(70~84) / 🔸 弱(<70)**。

## 分析框架（AI 在候选表之上生成报告）

### 一、先讲清「有没有」
一句话：当前板块/行业里**有没有**跌到箱体极低位 + 紧贴强支撑的票。若候选为 0，说明该板块整体处于「箱体中高位」或「已破位走坏」。

### 二、解读 top 候选（逐只）
对每只 top 候选讲清楚：
- **箱体位置**：现价在近 60 日箱体的哪个位置（pos_pct%），离箱底多近
- **支撑情况**：最近支撑位在哪、现价距支撑多远（dist_pct%）、下方有几个支撑共振（强支撑还是单一支撑）
- **风险提示**：本 skill 只看「位置 + 支撑」，**不代表它不会继续跌**——贴支撑可能是止跌位，也可能是下跌中继；放量跌破支撑就是破位。

### 三、买点与止损（对确认候选）
- **买点**：现价贴支撑、未破位时，可在支撑位上方分批埋伏；跌破支撑则离场。
- **止损**：跌破最近支撑位（或箱体下沿）收盘确认，纪律止损——「到达强支撑」的反面就是「跌破强支撑」。

### 四、风险提示（每次必带）
- 「箱体极低位 + 强支撑」是**必要不充分**的买点：它可能继续阴跌、可能基本面暴雷，务必叠加基本面/资金确认（对单只跑 stock-analysis，或查 /news-search、/fund-flow）。
- 以上是公开行情的纯技术分析，不构成投资建议，独立决策。

## 注意事项

- **数据源**：成分股池（app.board_pool）、日 K 线（新浪）。**纯技术维度，不依赖 `MX_APIKEY`、不做基本面门槛**。
- **只做一个维度**：本 skill 刻意排除缩量/超卖/企稳/估值等维度，保持「强支撑 + 箱体极低位」的纯粹性。若要完整左侧逻辑，用 left-side；若要精确支撑/压力位，对单只跑 stock-analysis。
- **箱体口径**：`pos_pct` 用近 60 日高低，代表「近期区间位置」，不管是否震荡箱体（趋势下跌中的低位也会命中）。
- **不臆造**：脚本没查到的（基本面、利空事件、机构持仓）不要编造，需要时叠加对应 skill 补查。
- **芯片 vs 半导体**：行业名「半导体」成分更全，概念名「芯片」可能只命中子概念；查全行业请用「半导体」。
