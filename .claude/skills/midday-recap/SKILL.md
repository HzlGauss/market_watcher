# 中午复盘（midday-recap）

午间休市（11:30–13:00）对 `holdings.csv` 里 `show_flow=1` 的标的做**轻量中午复盘**：上午走势 + 技术阶段 + 上午主力资金 + 大盘环境，据此给**下午操作结论**（加/减/持有/做T挂单价），并覆盖写回 memory 的 `holdings-closing-recap.md`。

> 与收盘复盘(closing-recap)同源，但口径是**上午半日**，且多「下午操作价」这一层。收盘复盘收盘后再跑会覆盖本文件。

## 用法

```bash
py .claude/skills/midday-recap/midday_holdings.py
```

**午间休市（11:30–13:00）跑**。脚本读 `holdings.csv` 里 `show_flow=1` 的标的，逐个打印紧凑复盘块 + 汇总表。

## 数据源（本地优先，妙想兜底）

| 字段 | 首选 | 兜底 | 说明 |
|---|---|---|---|
| 上午收盘价/涨跌幅 | 实时快照（新浪+腾讯 `fetch_quotes`） | 本地资金流快照 `price` → 妙想 | 午间取到的是 11:30 上午定盘 |
| 上午主力净流入 | `data/fund_flow_intraday.duckdb` 最后一条（东财源，上午累计） | 妙想 | **须落库到 11:15 之后才用本地**；否则东财反爬中午停更、上午累计失真，回退妙想 |
| 近5日累计 / 连续流入天数 | 妙想 | — | 本地无历史资金流（`push2his` 被 IP 封锁） |
| ETF 净申购额 | 妙想 | — | 可能为空（妙想未返回，属正常） |
| 技术面（均线/RSI/MACD/KDJ/箱体/阶段） | 本地 `data/market.duckdb` 日K + 远端补当日缺口 | 新浪 | `fetch_daily_hybrid` |
| 大盘环境（指数/广度/情绪） | 新浪指数 + 东财 clist 广度 | — | 4 核心指数涨跌 + 涨跌家数/成交额/上涨占比 |
| 下午加减仓信号 | `evaluate_position_signal`（日K `detect_stage` → 加/减 + 挂单价） | — | 与 scan_position 同引擎 |
| 下午做T信号 | `evaluate_t0_measure`（5 分钟 K 三门槛 + 量价背离） | — | 与 scan_t0 同引擎 |

个股主力 = 超大单 + 大单；ETF 主力 = 主力净流入（+ 净申购额，申赎口径）。

## 输出字段解读

- `上午收 价(+涨跌%)`：11:30 上午收盘价 + 半日涨跌幅。
- `多头排列/空头排列/多头回调`：均线方向；`MA5/10/20/60`。
- `支撑X/压力Y`、`箱体[lower,upper]现价X%`、`阶段:...(置信%) 趋势/量能/动量`：同收盘复盘。
- `资金: 上午主力 X亿·截至HH:MM`：上午累计主力净流入；`·截至` 标注本地快照落库时刻；无标注 = 妙想全天口径（异常时）。
- `⚠️价涨主力出货 / 价跌主力吸筹`：量价背离提示。
- `[下午] 加减仓: 🟢加仓(右侧)/🟡加仓(左侧埋伏)/🟠加仓(左侧接刀)/🔴减仓 阶段[..] 置信.. 挂单 xx~xx`：下午加减仓信号 + 建议挂单价。`无信号` = 主升浪/震荡市持股为主。
- `[下午] 做T: ✅适合 买 x / 卖 x（振幅..%）` 或 `❌ 不适合（原因）`：下午做 T 可行性 + 挂单价。

## 生成下午操作结论（AI 分析框架）

对每个标的，结合四件事给结论：

1. **大盘环境（【0】）**：指数普涨+上涨占比>70% = 进攻，买入类可信度高；普跌+<30% = 防守，买入降级/卖出升级；分化 = 按个股信号、仓位减半。
2. **上午走势 + 趋势阶段**（多头/空头/震荡 + 阶段）→ 顺还是逆。
3. **上午主力方向**（上午 + 近5日累计 + 连续天数）→ 资金是否站在你这边。
4. **下午信号**（加减仓 + 做T）→ 给具体加/减/做T挂单价。

产出四要素：**下午结论**（持有 / 加 / 减 / 清 / 空仓观望 / 做T）+ **关键价位**（下午买点 / 卖点 / 做T挂单价 / 止损）+ **一句话理由** + **下一步触发信号**。

不套统一模板：周期股（如紫金）锚在商品价格（金价），成长股锚在业绩/估值，ETF 看指数/板块趋势 + 申赎。已有单只深挖 memory 的（[[zijin-mining-entry-tracking-2026-11-02]]、[[shengbang-analysis-2026-11-05]]、[[siwitewei-entry-tracking-2026-11-02]] 等）结论以那为准，这里只做「上午快照 + 下午方向更新」。
