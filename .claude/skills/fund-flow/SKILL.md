# 查询单标的最近 N 个交易日资金流入（妙想）

查询某只 A 股或场内 ETF 的最近 N 个交易日资金流向，输出 5 档净流入（主力/超大单/大单/中单/小单），按交易日倒序排列。

## 用法

运行打包脚本，传入 6 位代码、可选名称、可选跟踪天数：

```bash
py .claude/skills/fund-flow/query_fund_flow.py <代码> [名称] [天数]
```

示例：

```bash
py .claude/skills/fund-flow/query_fund_flow.py 300432 富临精工        # 今日（或最近1个交易日）
py .claude/skills/fund-flow/query_fund_flow.py 300432 富临精工 3      # 最近3个交易日
py .claude/skills/fund-flow/query_fund_flow.py 159801 3               # ETF，不带名称，最近3个交易日
```

参数说明：

- **代码**（必填）：6 位 A 股 / 场内 ETF 代码。
- **名称**（可选）：提升查询精度，可省略。
- **天数**（可选，默认 1）：`1` = 今天（当天是交易日的话）或最近 1 个交易日（非交易日）；`2`/`3`/… = 最近 2/3/… 个交易日。上限 30。

## 脚本输出与解读

- 表格按**交易日倒序**（最新在上），今天那行会标注 `(今日·实时)`。
- 数值单位为**亿元**，`+` 为净流入、`-` 为净流出。
- `主力 = 超大单 + 大单`，`散户 ≈ 小单`。
- `N/A` = 该档该日无数据（妙想对 ETF 的历史数据常缺「中单」档，属正常）。
- 脚本先走结构化解析；若失败则回退打印妙想自然语言原始结果。
- **备用通道（东方财富兜底）**分两种情况自动触发：
  1. **妙想完全无数据**（结构化 + 单日接口都拿不到）：直接走东方财富 `push2delay` 实时通道获取「今日·实时」5 档净流入，输出标题会标注「东方财富兜底」。
  2. **妙想实时通道失效**（最新返回日期早于今日）：用东方财富补「今日·实时」这一行，与妙想历史日线合并展示。

## 注意事项

- **依赖**：需在 `.env` 配置 `MX_APIKEY`（可选 `MX_APIKEY_2` 备用），否则脚本会提示无 key。
- **备用通道**：东方财富 `push2delay` 兜底只补「今日实时」这一行，历史多日仍走妙想；两者单位/口径一致（亿元、5 档净流入），可直接横比。妙想对科创板 ETF（如 `588xxx`）等覆盖不全时，建议**带名称**查询以提升匹配精度，实在拿不到数据时该兜底会自动接住。
- **ETF 口径**：场内 ETF 的「资金流向」是**二级市场成交拆单口径**，反映场内交易资金方向，**不等于**基金申赎净额；解读 ETF 时应结合份额申赎与跟踪指数/板块走势。
- **时效**：数据为实时（仅交易时段有效），盘中会随行情刷新，非交易时段可能无数据。
- **交易日识别**：妙想「近N日」按自然日计，脚本会多请求约 1.5× 日历天数覆盖周末再截取前 N 个交易日；遇长假（如春节/国庆）可能不足，此时可手动调大天数重试。
