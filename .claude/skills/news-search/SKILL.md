# 财经资讯搜索（妙想）

用妙想 `fin_search` 接口按自然语言关键词搜索新闻/公告/研报，按类型分组返回，含评级、机构、关联证券等结构化字段。

## 用法

```bash
py .claude/skills/news-search/search_news.py <关键词> [小时]
```

示例：

```bash
py .claude/skills/news-search/search_news.py 宁德时代 减持
py .claude/skills/news-search/search_news.py 半导体板块 利好 24
py .claude/skills/news-search/search_news.py 贵州茅台 研报 目标价
```

参数说明：

- **关键词**（必填）：自然语言搜索词，支持「公司/板块/题材 + 事件类型」组合。
- **小时**（可选，默认最近 7 天）：只保留最近 N 小时内的资讯。传 `24` = 最近 24 小时。

## 脚本输出与解读

- 按 `information_type` 分四组：**研报**（REPORT，含评级/机构）、**公告**（ANNOUNCEMENT）、**新闻**（NEWS）、**其他**。
- 每条资讯给出：标题 + `[评级, 机构, 来源, 日期]` + 关联证券（`secu_list`，题材新闻→个股映射）+ 链接 + 内容摘要。
- 已按日期降序 + 标题去重（同一事件多来源转载只留一条）。

## 分析框架（AI 在数据包之上生成结论）

1. **事件定性**：区分利好/利空/中性，标注事件类型（业绩预告、减持/增持、回购、解禁、立案/处罚、政策、行业景气）。
2. **影响标的**：从「关联证券」列提取受影响的个股/板块，说明影响方向。
3. **时效与持续性**：按日期判断是当日突发还是历史事件，评估持续性（一次性 vs 趋势性）。
4. **结论**：一句话总结该关键词对应的最新消息面，及其对相关标的的潜在影响。

## 注意事项

- **依赖**：需在 `.env` 配置 `MX_APIKEY`（可选 `MX_APIKEY_2` 备用）。
- **研报评级**：`rating` 字段仅在 `information_type=REPORT` 时出现（买入/增持/中性/减持等）。
- **关联证券**：题材类搜索（如「半导体 利好」）的 `secu_list` 会给出新闻映射到的个股，可直接用于「题材→个股」挖掘。
- **窗口过滤**：小时窗口过滤基于妙想返回的 `date` 字段；若过滤后为空，脚本会回退到全部资讯。
