# 磨底扫描（bottoming）

对**指定板块/行业**做「磨底」扫描：在成分股里找出「**已经止跌（不再创新低）、在低位窄幅横盘、成交量萎缩**」的票。这是**底部左侧买入中最安全的一段**——比 left-side（还在跌、接飞刀）多了「止跌确认」，比 right-side（已突破）早了启动前。

与其它 skill 的分工：

- **`left-side`**：标的可能**仍在下跌**（超跌埋伏、接飞刀），未见底确认。
- **`bottoming`（本 skill）**：标的**已止跌**，在底部横盘缩量打底，尚未启动。左侧埋伏中最稳的一段；但回测显示它是**熊市里的 5~10 日超跌反弹**，不是长线抄底（见「回测结论」）。
- **`right-side`**：已放量突破启动，顺势追（右侧）。
- **`golden-pit`**：磨底在「白马蓝筹 + 深坑（回撤≥20%）」里的特例，本 skill 不限白马成色、不限深坑。
- **`support-box`**：纯「箱体低位 + 强支撑」位置维度，不看缩量/止跌/时长。

## 用法

```bash
py .claude/skills/bottoming/scan_bottoming.py <板块/行业|白名单/CSV> [输出数量] [--sync] [--full]
```

示例：

```bash
py .claude/skills/bottoming/scan_bottoming.py 半导体
py .claude/skills/bottoming/scan_bottoming.py 创业板 20
py .claude/skills/bottoming/scan_bottoming.py 沪深300 15
py .claude/skills/bottoming/scan_bottoming.py 化工
py .claude/skills/bottoming/scan_bottoming.py 白马蓝筹
```

参数说明：

- **板块/行业**（必填）：支持四类输入——
  - **指数**：沪深300 / 中证500 / 中证1000 / 上证50 / 中证红利 / 科创50 / 创业板指
  - **板**：创业板 / 科创板（全板成分，非指数）
  - **行业/概念**：半导体 / 芯片 / 化工 / 白酒 / 光伏 / 新能源 / 医药 / 军工 ...（板块名模糊匹配）
  - **白名单/CSV**：关键词「白马蓝筹/蓝筹白马/白名单」→ `data/bluechip_whitelist.csv`（自带 ROE今%/净利同比%/PB分位% 快照，输出表直接附上、免重复拉取）；或任意本地 `.csv` 文件路径（须含「代码」列，可选「名称/层级」列）
- **输出数量**（可选，默认 20）：输出候选数量上限。
- **`--sync`**（可选）：先增量同步本地 marketdb 到最新。
- **`--full` / `--no-prescreen`**（可选）：跳过本地库 streaks 初筛，全池逐股拉 K 线（更慢但召回最全）。

## 扫描流程

解析成分股池 → **（池 ≥40 只时）先用本地 marketdb streaks 初筛「连续缩量」缩小范围** → 对候选逐股拉 250 根日 K 线 → 跑磨底检测打分 → 硬门槛筛掉「仍下跌 / 箱体过宽 / 未缩量 / 已启动」→ 按信号分排序输出候选表。**成分股池用 app.board_pool，K 线走本地 duckdb 前复权日 K（`fetch_daily_local_first`，缺该标的才回退新浪），纯技术维度、不依赖 `MX_APIKEY`**；初筛后通常 10~60 秒。streaks 初筛按本地库快照（可能落后最近交易日），最终打分仍逐股用本地日K复核，故初筛只减请求、不改变单股结论。

## 磨底检测逻辑（六层）

1. **止跌（不创新低）**：现价距近 60 日最低收盘的「距低点%」落在 **0%~8%**（硬门槛）——`≥0` 不再创新低、`≤8%` 尚未涨离底部；`<0`（创新低）= 仍在跌，`>8%` = 已涨离底部。
2. **磨底时长**：该低点距今 **≥10 交易日**（硬门槛）——止跌后横盘足够久，排除「下跌中继」（短暂企稳又跌）。越长越充分（20~40 日最佳）。
3. **横盘窄幅（箱体压缩）**：近 60 日真实高低区间（箱宽 = 高低/下沿）**≤20%**（硬门槛）——窄幅横盘，非单边趋势。
4. **缩量打底**：近 20 日均量 / 近 120 日均量 **<0.8**（硬门槛）——抛压衰竭、地量见底；`<0.6` 更佳。
5. **企稳**：站回 MA5/MA10/MA20 = 止跌确认（加分）。
6. **未启动**：排除 `detect_stage` 判「启动期/主升浪/赶顶期」及 RSI >65 的已反弹到位标的（交还 right-side）；`detect_stage` 判「磨底期」+ 均线缠绕加分。

### 评分（0~100）

- 止跌贴底 **20**：距低点 ≤2% 满 → 6~8% 只 8
- 箱体压缩 **20**：箱宽 ≤10% 满 → 15~20% 只 12
- 缩量 **20**：<0.6 满 → 0.6~0.8 只 14
- 磨底时长 **15**：≥40 日满 → 10 日只 6
- 企稳 **15**：站 MA20 +8 / 站 MA10 +4 / 站 MA5 +3
- 阶段确认 **10**：`detect_stage` 判磨底期 +6 / 均线缠绕 +4

分级：**✅ 强(≥75) / ⚠️ 中(55~74) / 🔸 弱(<55)**。

## 回测结论（牛熊门控）

`backtest_bottoming.py`（中证1000 774 只，8 采样日）按板块广度重建每日牛熊后分桶：

- **牛市里磨底是反向**：20 日 -5.3%、胜率 10.5%——「牛市禁左侧埋伏」（`gate_side` 已在线抑制）。
- **熊市里磨底是 5~10 日超跌反弹**：5 日 +1.6%、胜率 69.6%；但 20 日仍负。
- **紧条件 5~10 日 edge 最好**：距低点≤2% + 深度缩量(<0.6) + 磨底 10~19 日。

**定位**：磨底按「熊市 + 短线 5~10 日兑现」用，别当「买完拿 20 日」的长线抄底。

## 分析框架（AI 在候选表之上生成报告）

### 一、先讲清「有没有止跌磨底的票」
一句话结论：当前板块/行业里**有没有**已止跌、正在磨底的候选，及整体「打底充分度」。候选为 0 说明该板块整体仍在下杀、趋势市、或已启动。

### 二、解读 top 候选（逐只）
- **止跌了没**：距低点%（0% 贴底 / 8% 已抬升一点）、磨底多少天——磨底要「跌不动 + 横得住」，不是「还在创新低」
- **横盘窄不窄**：箱宽%（≤20% 窄幅）；**缩没缩量**：缩量比（<0.6 地量确认真缩量）
- **企稳了没**：站 MA20？——磨底是「跌得差不多 + 缩量横盘」，不是「已经放量突破」（那是 right-side）

### 三、买点与止损（对确认候选）
- **买点**：现价在箱体下沿附近、缩量未破位时分批埋伏（磨底左侧不打满）；或等放量站上箱体上沿 = 右侧确认再加
- **持有周期**：磨底是**短线反弹信号**，默认 **5~10 交易日兑现**（熊市最优），反弹到箱体上沿 / 放量滞涨即分批了结，不恋战拖成 20 日趋势
- **止损**：跌破箱体下沿（近 60 日最低）或磨底锚点收盘确认，纪律离场——磨底失败 = 破位补跌，不可扛单

### 四、风险提示（每次必带）
- 磨底是「止跌后的左侧埋伏」，**仍可能破位补跌、磨底时间不可测**，务必分批 + 止损
- **只在熊市有效**：牛市已由 `gate_side` 在线抑制；震荡市样本少、方向不稳。且是**短线 5~10 日反弹**，不是长线趋势
- 白名单/CSV 输入若命中「净利同比<0 / PB分位>70 / ROE<8」快照 = 价值陷阱，警惕「磨底」实为「阴跌中继」
- 以上是公开行情/技术指标的分析，不构成投资建议，独立决策

## 注意事项

- **数据源**：成分股池（app.board_pool）、日 K 线（本地 duckdb 前复权 + 新浪兜底）。**纯技术维度，不依赖 `MX_APIKEY`、不做远端基本面门槛**；白名单/CSV 输入的 ROE/净利/PB分位 为筛选当日快照（非实时）。
- **「磨底」与「下跌中继」的分野是本 skill 的灵魂**：靠「距低点%∈[0,8] + 低点距今≥10日 + 箱宽≤20% + 缩量<0.8」四条硬门槛区分。缺一条（尤其「低点太近」）就可能只是阴跌途中的短暂企稳。
- **缩量口径**：本 skill 用「近20日均量/近120日均量」（当前是否地量），与 left-side/golden-pit 的「回调段均量/高点前20日均量」不同——磨底关注「当前地量」，而非「回调段 vs 高点前」的对比。
- **不臆造**：脚本没查到的（具体利空事件、主力资金是否回流、机构持仓）不要编造；需要时叠加 `/fund-flow` 查主力是否回流、`/news-search` 查利空/减持/解禁。
- **确认单只**：候选是初筛，确认买点/止损/基本面时对单只跑 `stock-analysis`（通用）或 `golden-pit`（白马）细看。
