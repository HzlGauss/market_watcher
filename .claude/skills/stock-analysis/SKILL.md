# 个股分析（诊股）

查询某只 A 股的基本面、估值、走势、技术指标、筹码、资金流与消息面，输出结构化数据包，并据此给出估值判断、风险点、未来机会、走势预测与买卖参考。

## 用法

```bash
py .claude/skills/stock-analysis/analyze_stock.py <代码> [名称] [天数]
```

示例：

```bash
py .claude/skills/stock-analysis/analyze_stock.py 300432 富临精工
py .claude/skills/stock-analysis/analyze_stock.py 300436 广生堂 60
```

参数说明：

- **代码**（必填）：6 位 A 股代码。
- **名称**（可选）：提升查询精度，可省略。
- **天数**（可选，默认 30）：拉取的日 K 线根数，上限 60。**建议传 60**，否则 MA60、MACD、箱体区间会因数据不足而缺失（30 根仍可出 MA5/10/20）。

脚本输出 **8 段数据包**（个股）：

- **① 基本信息**：简称/行业/最新价/涨跌幅/PE/总市值 + **板块识别**（科创/创业/主板/北交所，影响涨跌幅限制与波动属性）
- **② 近 N 日 K 线 + 技术面**：MA5/10/20/60、均线排列、RSI、MACD、KDJ、BOLL、支撑/压力/ATR、技术信号（跳空/突破/OBV/受压回落等）、箱体区间与现价位置、区间涨跌幅、逐日 K 线（含涨跌幅/换手）
- **③ 近 5 日资金流**：5 档净流入（主力/超大/大单/中单/小单）+ 累计 + **连续净流入/流出天数** + **价量背离**（价跌主力逆势吸筹 / 价涨主力出货）
- **④ 筹码与机构持股**：机构持股比例合计（环比 pp 变化）+ 股东户数（减少=筹码集中）
- **⑤ 基本面**：营收/净利/同比/ROE/毛利率/负债率 + 机构预测净利 + **分红方案/股息率**
- **⑥ 估值分位**：PE/PB 绝对值 + 3 年历史百分位
- **⑦ 最近研报**：评级/机构/日期 + **一致预期评级分布** + 目标价
- **⑧ 近 7 日资讯 + 事件风险**：新闻/公告/研报 + **减持/增持/回购/解禁/质押/业绩预告/立案/处罚**

### ETF 自动识别与分支

脚本按代码前缀自动识别 ETF（沪 51/56/58、深 15/16/18 开头），识别后**切换为 ETF 专属维度**（②技术面与③资金流仍通用）：

- **① 基本信息（ETF）**：最新价/涨跌幅/成交额/基金规模 + **跟踪指数名称**
- **④ ETF 专属指标**：**折溢价率**（日粒度，越接近 0 越好）、**基金份额**（日粒度 + 报告期申赎变化）、**跟踪误差**（偏离基准越小越好）、**基金规模**（资产净值，报告期）
- **⑤ 跟踪指数估值分位**：**跟踪指数的 PE/PB + 历史百分位**（看指数贵贱，非个股盈利估值）
- **⑧ 资讯 + 事件风险**：改为 **成分股调整 / 清盘 / 限额 / 折溢价异常 / 分红**（无减持/解禁概念）
- **跳过**⑥个股估值分位、⑦研报评级（ETF 无财报/研报/目标价）

ETF 分析时，AI 报告框架的「基本面/估值」段改为「跟踪指数估值 + 折溢价 + 份额申赎」，「消息面」段看成分股动态与折溢价异常。ETF 无个股黑天鹅，但有行业/主题板块性风险与流动性风险。

## 分析框架（AI 在数据包之上生成报告）

严格按以下 10 段组织输出：

### 一、公司是什么
从「①基本信息 + ⑤基本面」提炼：行业归属、主营业务/题材标签、**板块归属**（科创/创业/主板/北交所）、**盈利还是亏损**（PE 正负）、估值水平、总市值、成长性。一句话说清它「靠什么、赚不赚钱、处在什么赛道」。

### 二、基本面与成长性
从「⑤基本面」提炼，关键结论放句首（如「高成长+高盈利质量」/「增收不增利」/「利润下滑」）：
- 营收与净利的绝对规模、同比增速、**单季度环比**（是否边际改善/恶化）
- 盈利质量：ROE、销售毛利率（竞争力）、资产负债率（杠杆风险）
- 成长预期：机构预测净利中值未来 2-3 年趋势（加速/放缓/见顶）
- **股东回报**：分红方案 + 股息率（结合现价，高股息是防御属性）

### 三、估值分位（贵还是便宜）
从「⑥估值分位」判断：当前 PE/PB 绝对值 + 3 年历史百分位（<20% 低估 / 20%~50% 偏低 / 50%~80% 偏高 / >80% 高估）。**结合成长性**给一句话结论。亏损股（PE 为负）改用 PB 或 PS 判断。

### 四、最近的走势（关键结论放句首）
从「②K线+技术面 + ③资金流 + ④筹码」判断**当前处于什么趋势阶段**（单边下跌 / 单边上涨 / 箱体震荡 / 见顶回落 / 探底企稳），用「关键结论：xxx」开头。然后列：
- 阶段走势表（近几个关键节点：见顶、暴跌、探底、反弹、回踩）
- 技术位：MA5/10/20/60 与现价关系（站上/跌破/缠绕）、均线排列（多头/空头/缠绕）、RSI/MACD/KDJ/BOLL 多空信号、箱体/支撑/压力区间
- 资金流信号：**主力 vs 散户方向**、5 日累计、连续净流入/流出天数、是否有「价跌但主力逆势净流入」的背离
- 筹码信号：机构持股比例环比变化（加仓/减仓）、股东户数增减（筹码集中/分散）

### 五、消息面与研报观点（偏多/偏空标注）
从「⑧资讯 + ⑦研报」提炼：
- 新闻/公告催化，用 ✅/➖ 标注多空：产能扩张、订单、专利、减持、解禁等。区分「真实业绩催化」与「纯题材概念」。
- **事件风险**（⑧）：减持/增持/回购/解禁/质押/业绩预告/立案处罚，逐条判断是利好还是利空，减持/解禁是明确压力信号。
- 研报评级：列出最近评级（买入/增持/中性/减持）与机构，判断「机构是否一致看好」还是「分歧较大」；**一致预期评级分布** + 目标价（若有）。

### 六、风险点
综合基本面/估值/技术/资金/筹码/消息，提炼 **3~5 条具体风险**，每条给「触发信号」。落到「什么信号出现说明风险兑现」（如：业绩增速见顶 / 估值分位过高透支 / 主力连续净流出 / 机构持股环比下降 / 减持解禁临近 / 行业景气下行 / 高负债率）。

### 七、未来机会
综合成长性/催化/产业趋势，提炼 **2~4 条机会**，每条给「验证信号」（如：新产品放量、订单/产能扩张、机构加仓、股东户数下降筹码集中、估值修复、产业景气上行）。

### 八、走势预测（概率排序，3 个情景）
给出 3 个情景并按概率排序（合计≈100%），每个情景对应一个**具体价位区间**与触发条件。核心观察点列 2-3 条（如：能否缩量止跌 / 主力是否连续净流入 / 是否放量突破某关键位）。

### 九、是否值得买入 & 买入价（表格）
先给**一句话结论**（值得/不值得/观望博弈，及理由）。再用表格给分档策略：

| 策略 | 参考价位 | 逻辑 |
|---|---|---|
| 回踩支撑分批（首选） | 支撑位 | 箱体下沿/近期低点，赔率好 |
| 右侧突破（更稳） | 突破位 | 放量突破关键压力确认 |
| 当前价追入 | 现价 | ❌/⚠️ 中性/不推荐 + 理由 |

**止损参考**单独一行：跌破某关键位（收盘确认）止损。

### 十、免责声明（每次必带）
固定加一句：以上是基于公开行情/资金流/资讯/财报的技术与基本面分析，不构成投资建议；个股风险（高波动/亏损/题材/估值）提示 + 独立决策。

## 注意事项

- **数据源**：全部走妙想 Miaoxiang，需 `.env` 配置 `MX_APIKEY`（可选 `MX_APIKEY_2`）。
- **技术面口径**：复用 `app/technical.py` 的 `get_technical_summary`（MA/RSI/MACD/KDJ/BOLL/支撑压力/信号）+ `detect_box_regime`（箱体）。**MA60/MACD/箱体需 ≥60 根 K 线**，30 根会显示「数据不足」属正常，建议传天数 60。
- **资金流口径**：个股「主力 = 超大单 + 大单」；`N/A` = 该档无数据（正常）。若当日实时数据缺失，可叠加 `/fund-flow` 用东财兜底补「今日」。
- **筹码口径**：④ 机构持股比例为报告期粒度（中报/季报，滞后），股东户数为日粒度；二者结合看「机构动向 + 筹码集中度」。
- **基本面口径**：⑤ 取最新几期财报（报告期 + 单季），营收/净利为含少数股东口径；机构预测净利为市场中值（日期会变，只看趋势）；股息率 = 每股股利/现价，脚本已折算。
- **估值分位口径**：⑥ 是 3 年历史百分位，非上市满 3 年或数据缺失时可能无值，此时直接看 PE/PB 绝对值并结合行业横向比较。
- **板块识别**：① 已标注科创/创业/主板/北交所，注意科创板(688/689)、创业板(300/301) 涨跌幅限制为 20%，北交所 30%，波动属性不同，判断走势/止损时需考虑。
- **不臆造**：脚本没查到的数据（如更早的 K 线、细分财务科目、研报目标价）不要编造；需要时再补查或用 `technical.py` 算 RSI/MACD/KDJ。风险点与未来机会是 AI 基于数据包的综合判断，不是脚本直接输出，需有数据支撑。
- **预测是概率判断，不是保证**：始终给区间与触发条件，避免「必涨/必跌」的绝对表述。
