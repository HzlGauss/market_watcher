# 个股分析（诊股）

查询某只 A 股的基本面、走势、资金流与消息面，输出结构化数据包，并据此给出走势预测与买卖参考。

## 用法

```bash
py .claude/skills/stock-analysis/analyze_stock.py <代码> [名称] [天数]
```

示例：

```bash
py .claude/skills/stock-analysis/analyze_stock.py 300432 富临精工
py .claude/skills/stock-analysis/analyze_stock.py 300436 广生堂 30
```

参数说明：

- **代码**（必填）：6 位 A 股代码。
- **名称**（可选）：提升查询精度，可省略。
- **天数**（可选，默认 30）：拉取的日 K 线根数，上限 60。

脚本输出 4 段数据包：**① 基本信息**（简称/行业/最新价/涨跌幅/PE/总市值）→ **② 近 N 日 K 线 + 技术位**（MA5/10/20、近30/10日高低点、区间涨跌幅）→ **③ 近 5 日资金流**（5 档净流入 + 累计）→ **④ 近 7 日资讯**（新闻/公告/研报）。

## 分析框架（AI 在数据包之上生成报告）

严格按以下 6 段组织输出：

### 一、公司是什么
从「①基本信息」提炼：行业归属、主营业务/题材标签、**盈利还是亏损**（PE 正负）、估值水平（PE 高低）、总市值。一句话说清它「靠什么、赚不赚钱」。

### 二、最近的走势（关键结论放句首）
从「②K线+技术位」判断**当前处于什么趋势阶段**（单边下跌 / 单边上涨 / 箱体震荡 / 见顶回落 / 探底企稳），用「关键结论：xxx」开头。然后列：
- 阶段走势表（近几个关键节点：见顶、暴跌、探底、反弹、回踩）
- 技术位：MA5/10/20 与现价关系（站上/跌破/缠绕）、箱体/支撑/压力区间（用近30日与近10日高低点 + MA 交叉确定）
- 资金流信号：**主力 vs 散户方向**、5 日累计、是否有「价跌但主力逆势净流入」的背离（结合③）

### 三、消息面（偏多/偏空标注）
从「④资讯」提炼催化，用 ✅/➖ 标注多空：产能扩张、订单、专利、评级、减持、解禁等。区分「真实业绩催化」与「纯题材概念」。

### 四、走势预测（概率排序，3 个情景）
给出 3 个情景并按概率排序（合计≈100%），每个情景对应一个**具体价位区间**与触发条件。核心观察点列 2-3 条（如：能否缩量止跌 / 主力是否连续净流入 / 是否放量突破某关键位）。

### 五、是否值得买入 & 买入价（表格）
先给**一句话结论**（值得/不值得/观望博弈，及理由）。再用表格给分档策略：

| 策略 | 参考价位 | 逻辑 |
|---|---|---|
| 回踩支撑分批（首选） | 支撑位 | 箱体下沿/近期低点，赔率好 |
| 右侧突破（更稳） | 突破位 | 放量突破关键压力确认 |
| 当前价追入 | 现价 | ❌/⚠️ 中性/不推荐 + 理由 |

**止损参考**单独一行：跌破某关键位（收盘确认）止损。

### 六、免责声明（每次必带）
固定加一句：以上是基于公开行情/资金流/资讯的技术与基本面分析，不构成投资建议；个股风险（高波动/亏损/题材）提示 + 独立决策。

## 注意事项

- **数据源**：全部走妙想 Miaoxiang，需 `.env` 配置 `MX_APIKEY`（可选 `MX_APIKEY_2`）。
- **资金流口径**：个股「主力 = 超大单 + 大单」；`N/A` = 该档无数据（正常）。若当日实时数据缺失，可叠加 `/fund-flow` 用东财兜底补「今日」。
- **不臆造**：脚本没查到的数据（如更早的 K 线、财务细节）不要编造；需要时再补查或用 `technical.py` 算 RSI/MACD/KDJ。
- **预测是概率判断，不是保证**：始终给区间与触发条件，避免「必涨/必跌」的绝对表述。
