# 尾盘资金方向（close-drift）

收盘后（15:00 后）跑一次，对持仓/自选/指定板块的 A 股与 ETF，用**腾讯 1 分钟 K 线**近似「尾盘最后 3 分钟（收盘集合竞价）资金在抢还是逃」。脚本只取数排名，「尾盘资金方向 / 次日开盘铺垫」结论由 AI 依据下方框架生成。

> 说明：同花顺 `auction/snapshot` 端点只覆盖**开盘**集合竞价（`auction_price` ≡ `open_price`），官方 API 无尾盘竞价端点（无收盘竞价未匹配量/竞价换手）。故本 skill 用「14:56 连续竞价末价 vs 15:00 收盘竞价价」的漂移做**近似**，不是真正的集合竞价撮合数据。

与其他 skill 的分工：
- `auction` = 9:15–9:25 **开盘**竞价的盘前强弱（同花顺竞价快照）；
- **本 skill** = 14:57–15:00 **收盘**竞价的盘后资金方向（腾讯 1 分钟 K），是收盘后复盘与次日开盘铺垫的「探针」。

## 用法

```bash
py .claude/skills/close-drift/scan_close_drift.py                # 默认扫持仓+自选（含 ETF + A 股）
py .claude/skills/close-drift/scan_close_drift.py 半导体         # 扫指定板块/行业成分股
py .claude/skills/close-drift/scan_close_drift.py 600036,510300  # 扫指定代码列表
py .claude/skills/close-drift/scan_close_drift.py 半导体 20      # 指定板块 + 输出上限
```

脚本输出 **1 段排名表**：按「尾盘漂移」降序，列 代码/名称/类型(个股|ETF)/尾盘漂移/14:56价/收盘价/竞价量(手)/当日涨跌，并统计 `>+0.3%` 抢筹 / `<-0.3%` 砸盘家数；未收盘/无数据的标的单独列出。

## 分析框架（AI 在数据包之上生成报告）

### 一、尾盘漂移方向
- **漂移明显为正（> +0.3%）+ 竞价量大** = 尾盘竞价抢筹拉升，资金尾盘主动扫货，次日高开概率偏高。
- **漂移明显为负（< −0.3%）+ 竞价量大** = 尾盘竞价砸盘出逃，资金尾盘撤退，次日低开/承压概率偏高。
- **漂移接近 0 + 竞价量大** = 尾盘换手充分但方向不明，多空博弈，看次日竞价方向再定。
- **竞价量小** = 尾盘无人博弈，方向信号弱，参考意义有限。

### 二、结合当日涨跌
- 当日大涨 + 尾盘继续抢筹 = 强势延续（可能加速）；当日大涨 + 尾盘砸盘 = 冲高兑现、谨防次日回落。
- 当日大跌 + 尾盘继续砸盘 = 弱势加剧（杀跌未完）；当日大跌 + 尾盘抢筹 = 尾盘承接、可能止跌。

### 三、ETF 与个股分开看
- **ETF 有做市商平滑**，尾盘漂移天然更小，阈值可放宽到 ±0.15%；漂移虽小但竞价量巨大（十万手级）也值得留意。
- 个股漂移 0.3% 以上即算明显异动。

### 四、结论（一句话 + 操作提示）
先给**一句话结论**（今日尾盘资金整体是抢还是逃 + 哪些标的尾盘最强/最弱），再给操作提示（尾盘抢筹→次日关注、尾盘砸盘→次日开盘减仓/防守、平盘→观望）。

**免责声明**（每次必带）：以上基于公开 1 分钟 K 线对尾盘竞价的近似推断，不构成投资建议；尾盘漂移受做市商、大单拆单等因素干扰，务必独立决策、设好止损。

## 注意事项

- **数据源**：腾讯分钟 K（`ifzq.gtimg.cn`），免费，**不依赖 `MX_APIKEY` / `HITHINK_FINANCE_API_KEY`**。
- **范围**：A 股个股（60/68/00/30）+ 场内 ETF/LOF（51/56/58/15/16/18）；B 股/港股/北交所不支持。
- **时段**：需收盘后（15:00）跑才有 15:00 收盘竞价定盘数据；盘中跑会提示「尚未收盘」。非交易日显示最近交易日数据。
- **默认目标池**：`holdings.csv` + `watchlist.csv`（去重，持仓优先）；也可传板块/行业名（走 `board_pool` 解析成分）或逗号分隔代码列表。
- **近似而非竞价撮合**：看不到收盘竞价的未匹配量/竞价换手，仅「14:56→15:00 价格漂移 + 竞价量」两个维度。
- **不臆造**：脚本没查到的（具体尾盘催化消息、龙虎榜资金）不要编造，需要时叠加 `/news-search` 查题材催化、`/market-heat` 看热点方向。
