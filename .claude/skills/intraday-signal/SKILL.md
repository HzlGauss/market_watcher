# 盘中决策（intraday-signal）

盘中对单个标的（个股或场内 ETF）做一次「仓位决策 + 做 T + 抄底」判断。脚本只取数算指标，先输出【0 大盘环境】+【0b 盘中消息】+【0c 行业走势】三层环境包，再输出 6 段个股数据包；AI 在此基础上生成独立结论。

## 用法

```bash
py .claude/skills/intraday-signal/analyze_intraday.py <代码> [名称] [天数]
```

示例：

```bash
py .claude/skills/intraday-signal/analyze_intraday.py 300432 富临精工
py .claude/skills/intraday-signal/analyze_intraday.py 510300 沪深300ETF 60
py .claude/skills/intraday-signal/analyze_intraday.py 159915          # 不带名称
```

参数说明：

- **代码**（必填）：6 位 A 股 / 场内 ETF 代码（个股 60/68/00/30，ETF 51/56/58/15/16/18）。
- **名称**（可选）：提升妙想查询精度，可省略。
- **天数**（可选，默认 60）：拉取的日 K 线根数，上限 120。≥ 60 才能算出 MA60 与 MACD，趋势判断建议用默认值。

脚本先输出三层**环境数据包**，再输出 6 段个股数据包：

- **【0 大盘环境】**（环境过滤层，非买卖信号）：上证/深证/创业板/沪深300 四指数涨跌 + 全市场广度（上涨/下跌/平盘家数、上涨占比、成交额）+ 环境强弱标签。
- **【0b 盘中消息】**（风险提示层）：大盘快讯（新浪 7x24 实时，前 8 条）+ 个股新闻（东财，前 5 条），供 AI 判突发利好/利空。
- **【0c 行业走势】**（环境过滤层，非买卖信号）：个股所属行业（东财 f100 → 同花顺行业指数）的今日涨跌 + MA5/10/20 均线排列 + RSI(14) + 近 5/20 日涨幅 + 相对沪深300 强弱。ETF 无个股行业归属，此段自动跳过。
- **① 实时快照**（现价/涨跌幅/振幅/均价VWAP/量比/换手率/内外盘/委比/日内位置）→ **② 当日资金流**（5 档净流入 + 资金结构 + 净占比）→ **③ 近 N 日 K 线 + 趋势 + 量能**（MA5/10/20/60、均线排列、RSI/MACD/KDJ、布林、关键支撑压力、市场状态、量价关系、OBV能量潮、地量/滞涨检测）→ **④ 近 5 日资金流趋势**（5 档 + 累计）→ **⑤ 做 T 测算**（5 分钟 K 线支撑压力、日内振幅、市场状态、做 T 可行性判断；仅判定「✅ 适合」时才给出建议买卖挂单价，否则明确「❌ 不适合」及原因）→ **⑥ 抄底信号测算**（深度回撤 + 止跌形态正向确认；底背离/技术超卖/资金背离吸筹/靠近支撑仅参考，聚合判定「✅ 可尝试抄底 / ⚠️ 深跌未止跌 / ❌ 无抄底信号」）。

### 批量扫描（扫 holdings.csv 全持仓）

盘中想一次扫完持仓、列出「哪些适合做 T」和「哪些该加/减仓」时，用批量版（与单股版共用同一套评估函数，避免逻辑漂移）：

```bash
py .claude/skills/intraday-signal/scan_t0.py [数量]        # 做T批量：✅适合做T的排前 + 买/卖挂单价
py .claude/skills/intraday-signal/scan_position.py [数量]  # 加减仓批量：日K阶段→加/减仓 + 建议挂单价，按置信度降序
```

- **scan_t0**：逐标的拉 5 分钟 K 线跑三门槛（非单边 / 振幅够 / 区间够），✅ 适合做 T 的按振幅降序排前（含买/卖挂单价），❌ 的列原因；仅交易时段有意义，做 T 需已有底仓。
- **scan_position**：逐标的拉日 K 线跑 `detect_stage` 周期阶段 → 加/减仓动作（启动期/磨底期/下跌期=加，赶顶期/派发期=减），按置信度降序；日K级慢变量，盘中/盘后均可跑；「观察·无持仓」标记 holdings.csv 里 amount=0/空的观察标的。
- **扫描范围** = holdings.csv 全部标的（含观察标的）。与实时 `t0_monitor` 线程的自动推送互补：线程=被动提醒（节流+去重），scan=盘中主动拉一次的清单。

## 分析框架（AI 在数据包之上生成报告）

严格按以下 7 段组织输出：先「〇 环境过滤」，再「一~六」6 段个股。**核心：仓位层与做 T 层是两个独立结论，必须分开下，且允许并存**（例如「中期减仓」但「日内超跌可做 T 抄底」）。

### 〇、环境过滤层（【0】大盘环境 + 【0b】盘中消息 + 【0c】行业走势）
先自上而下读环境（大盘 → 消息 → 行业）、再读个股；**环境只做过滤/降级，不产生新的买卖信号**：
- **大盘方向（【0】）**：指数普涨 + 上涨占比 >70% = 进攻环境，个股「主力净流入 + 放量上涨」可信度高；指数普跌 + 上涨占比 <30% = 防守环境，个股上涨多为诱多/护盘，**买入类动作（建/加/抄底）降级、卖出类（减/清）升级**；指数分化 + 上涨占比 40~60% = 震荡，按个股自身信号、仓位减半。
- **行业方向（【0c】）**：个股所属行业整体趋势与相对强弱是第二层过滤器——行业多头排列 + 相对沪深300 强 = 个股顺水行舟，买入信号可信度加分；行业空头排列 / 相对大盘弱 = 个股再强也难独善其身，追涨需谨慎、抄底更要等行业企稳。个股自身强但**行业走弱**时，仓位动作降级；个股弱但**行业强势领涨**时，可关注是否补涨（但不因此机械买入）。
- **突发消息（【0b】）**：个股出现减持/问询/立案/业绩预降等**利空** → 一票否决抄底/追涨，即使技术面企稳也降级；出现大额中标/重组/业绩预增等**利好** → 仍看量价是否确认，不因消息直接买入。大盘快讯里的宏观/外盘（美联储、商品等）只作背景，判断对标的所在板块有无传导。
- 环境层数据为**盘中实时**，收盘后运行只作复盘参考。

### 一、标的现在什么位置（关键结论放句首）
从「①③」提炼，用「关键结论：xxx」开头。一句话说清：现价在今日高低区间的哪个位置（①日内位置）、在近 N 日趋势里的哪个阶段（③均线排列 + 市场状态 + 区间涨跌幅）、靠近支撑还是压力（③关键位）。

### 二、今日资金与量价配合（多空方向）
从「②④」判断资金方向，从「①」判断量价：
- **主力 vs 散户方向**（②5 档 + 资金结构标签）：机构主导 / 主力偏多 / 散户主导 / 机构出货等。
- **量价配合**（①）：涨跌幅 + 量比 + 换手率 + 内外盘 + 委比，判断「放量上涨（健康）/ 缩量上涨（乏力）/ 放量下跌（出货）/ 缩量下跌（抛压减轻）」。
- **量比 / 换手率阈值**：量比 `≥1.5` 明显放量、`0.8~1.5` 平量/温和、`<0.8` 缩量；换手率个股 `1%~3%` 正常、`3%~7%` 活跃、`>7%` 高换手（短线博弈）、`<1%` 清淡，**ETF 受 T+0/做市商影响仅作相对活跃度参考**。资金方向需与量能同向才可信：主力净流入 + 放量 = 有效吸筹，主力净流入 + 缩量 = 力度弱/护盘，主力净流出 + 放量 = 出货确认，主力净流出 + 缩量 = 抛压减轻。
- **量价关系 + OBV 能量潮**（③）：`量价关系`给出「放量/缩量/平量 × 上涨/下跌/震荡」；`OBV能量潮`给出资金趋势信号——顶背离⚠️=价涨量缩出货、底背离=价跌量增吸筹、加速/持续/转向流入流出；`地量`=交投清淡变盘前兆，`滞涨`=涨幅小却放量的出货嫌疑。OBV 顶/底背离与②资金背离可交叉验证，两者同向时信号更可靠。
- **背离信号**：价跌但主力逆势净流入（吸筹）、价涨但主力净流出（出货）。
- **5 日趋势**（④）：主力是否连续净流入/流出（比单日更可靠）。

### 三、仓位决策：建仓 / 加仓 / 减仓 / 清仓 / 不动（表格）
先给**一句话结论**（五个动作选一个，及核心理由）。再用表格给依据：

| 维度 | 信号 | 偏向 |
|---|---|---|
| 趋势（③市场状态/均线排列） | 趋势上涨/震荡/趋势下跌 | 顺势加减、逆势减 |
| 资金（②④） | 主力连续流入/流出、是否背离 | 流入偏建/加、流出偏减/清 |
| 量价（①） | 放量/缩量 + 涨跌 | 放量上涨偏加、放量下跌偏清 |
| 技术位（③支撑压力/RSI/KDJ） | 靠近支撑/压力、超买/超卖 | 低位偏买、高位偏卖 |

**动作判定参考**（非机械，需综合）：
- **建仓**：无底仓 + 趋势企稳/向上 + 主力净流入 + 现价靠近支撑或刚突破。
- **加仓**：已有底仓 + 趋势向上 + 主力持续流入 + 放量突破或回踩支撑。
- **减仓**：涨幅已高（靠近压力/RSI 超买）+ 主力净流出/量价背离，落袋部分。
- **清仓**：趋势转空（跌破关键支撑/均线空头）+ 主力大幅流出 + 放量下跌。
- **不动**：震荡市方向不明、信号冲突、数据不足时默认观望。

**抄底判定（⑥，独立下结论，与「建仓」区分）**：脚本【6】已按硬门槛分级「✅ 可尝试抄底 / ⚠️ 深跌未止跌 / ❌ 无抄底信号」，AI 严格遵循脚本分级：
- 抄底 = 逆势左侧，与「建仓」的顺势逻辑相反；核心信号是**深度回撤**（近20日跌幅 ≤ -15% 个股 / -10% ETF），**止跌 K 线形态是唯一被回测证实的正向确认**（深跌 + 止跌形态 → 20日 +10.2%、86.7% 胜率，与 left-side 独立回测交叉印证）。
- **更深 ≠ 更好**：跌超 -20% 无额外 edge（回测 20日 0%、胜率 50%），故不设「高确信」档，深跌幅度只作描述、不作加分。
- 底背离 / 技术超卖 / 资金背离吸筹 仅是**参考项**（回测显示叠加在深跌上无增量）；**靠近强支撑不作加分**（回测显示小盘股靠近支撑反而易跌穿，20日 -2.2%）。
- 脚本判「⚠️」（深跌但未见止跌形态）时：可轻仓埋伏、等止跌K线出现再加，不给满仓抄底价。
- 脚本判「❌」时，报告中明确写「不抄底」并复述原因，不给抄底价位。
- 脚本判「✅」时，用③支撑位给抄底参考区间与止损（跌破支撑即止损），并强调**轻仓、左侧、分批**，不做满仓押注。

**止损/止盈参考**单独写一行（用③支撑压力给关键位）。

### 四、是否适合做 T（结论 + 依据）
**稳健优先：默认不建议做 T。** 脚本【5】会**无条件输出参考挂单价**（技术位参考），但只有判定「✅ 适合」时才给出做 T 操作建议；脚本判定「❌ 不适合」时，报告中明确写「今日不适合 T+0 操作」并复述原因，挂单价仅作参考、不建议据此下单。

脚本已按硬门槛预判，AI 严格遵循，不得在脚本判「❌」后仍**建议**做 T（参考挂单价仍可列出，但必须醒目标注「仅参考、今日不适合 T+0」）。三条硬门槛（对应脚本「❌」的 reasons）：
1. **非单边**（⑤市场状态）：趋势上涨/趋势下跌 = 单边，**不提示做 T**；窄幅震荡 = 即将变盘，**不提示**。只有「震荡」类才考虑。
2. **振幅够**（⑤日内振幅 ≥ 门槛，ETF 0.8%/个股 1.5%）：不足则价差覆盖不了成本，**不提示**。
3. **区间够**（⑤支撑/压力区间 ≥ 0.8%）：过窄无利润空间，**不提示**。

若脚本判「✅ 适合」，用一句话说明「为什么适合」（震荡 + 振幅/区间充足），再进入「五」给挂单。若「❌」，说明等什么条件能转适合（如：等振幅放大 / 等单边结束回到箱体），并在「五」给出脚本输出的参考挂单价、醒目标注「仅参考、今日不适合 T+0」。

### 五、做 T 挂单（脚本【5】无条件输出参考挂单价；是否建议操作看判定）
以「⑤」的买卖挂单价为基准微调，给出表格：

| 方向 | 挂单价 | 逻辑 |
|---|---|---|
| 买单（低吸） | ⑤买单价 | 支撑上方留缓冲，避免挂太低不成交 |
| 卖单（高抛） | ⑤卖单价 | 压力下方留缓冲，避免挂太高不成交 |
| 止损/破位 | 跌破支撑 xx | 做 T 底仓保护 |

- **脚本判「✅ 适合」**：按上表正常给做 T 操作建议。
- **脚本判「❌ 不适合」**：仍列出参考挂单价，但**必须**醒目标注「⚠️ 今日不适合 T+0 操作（原因见四），以下仅为技术位参考，不建议据此下单」，不得写成可执行建议。

**正 T / 反 T 说明**（仅「✅」时展开）：有底仓做「正 T」（先买后卖）；仅想日内高抛低吸做「反 T」（先卖后买）需已有持仓。无持仓只能做日内「先买后卖」的正 T，且当天无法平仓（A 股 T+1），需提示风险。
**成本校验**单独一行：价差须 ≫ 双边佣金 + 印花税（卖出千 0.5），否则做 T 白忙。

### 六、免责声明（每次必带）
固定加一句：以上是基于公开行情/资金流/技术指标的量化分析，不构成投资建议；盘中数据实时变动，做 T 是高风险短线操作，请控制仓位、独立决策。

## 注意事项

- **数据源**：实时快照（新浪+腾讯）、当日资金流（东财分钟级 fflow）、日 K 线（本地 duckdb 前复权 + 远端补当日缺口，AKShare 兜底）、5 分钟 K 线（新浪，AKShare 兜底）、近 5 日资金流（妙想）、大盘环境（新浪指数 + 东财 clist 广度）、盘中消息（大盘快讯=新浪 7x24，个股新闻=东财，经 `fetch_market_news_cached` 与盯盘共用快讯缓存）、行业走势（个股所属行业=东财 f100 `fetch_stock_industry_map`，行业指数=同花顺 `fetch_index_kline`/`fetch_index_snapshot`，需 `HITHINK_FINANCE_API_KEY`，无 key 时【0c】静默跳过）。**核心功能不依赖 `MX_APIKEY`**，无 key 也能跑（仅【4】近 5 日资金流趋势会跳过）。
- **仓位决策与做 T 是两个层次**：仓位决策看日线趋势 + 资金趋势；做 T 看 5 分钟级别震荡。两者可能矛盾（中期看空但日内超跌可做 T），必须分两段写清楚，不能混成一句。
- **A 股 T+1 约束**：普通 A 股当日买入次日才能卖，做 T 只能基于「已有底仓」（先卖后买）或「买入后持有至次日」。ETF 部分品种支持 T+0，需标注品种差异。
- **ETF 资金流口径**：场内 ETF 的「资金流」是二级市场成交拆单口径，不等于基金申赎净额，解读时结合指数/板块走势。
- **时效**：数据为盘中实时（仅交易时段有效），收盘后运行得到的是当日收盘快照，做 T 结论失效，应提示「已收盘，仅供复盘」。
- **做 T 未经历史回测**：做 T 依赖 5 分钟级盘中数据（新浪 5 分钟仅回最近 ~2 天、AKShare 仅最近几周），无法与日K同长回溯，三道硬门槛为经验规则、未经严格历史回测，使用需谨慎。
- **不臆造**：脚本没查到的数据（财务、消息面等）不要编造；需要消息面可叠加 `/stock-analysis` 或 `/fund-flow`。
- **抄底是左侧逆势、高风险**：即使脚本判「✅」，也只是「深度回撤 + 止跌形态」的均值回归概率信号，仍可能继续下跌（接飞刀）；必须设好止损、轻仓分批，宁可错过不可满仓。
- **预测是概率判断，不是保证**：始终给关键位与触发条件，避免「必涨/必跌」「稳赚」的绝对表述。
