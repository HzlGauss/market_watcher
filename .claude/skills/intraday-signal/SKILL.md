# 盘中决策（intraday-signal）

盘中对单个标的（个股或场内 ETF）做一次「仓位决策 + 做 T + 抄底」判断。脚本只取数算指标，输出 6 段数据包；AI 在此基础上生成独立结论。

## 用法

```bash
py .claude/skills/intraday-signal/analyze_intraday.py <代码> [名称] [天数]
```

示例：

```bash
py .claude/skills/intraday-signal/analyze_intraday.py 300432 富临精工
py .claude/skills/intraday-signal/analyze_intraday.py 510300 沪深300ETF 60
py .claude/skills/intraday-signal/analyze_intraday.py 159915          # 不带名称
```

参数说明：

- **代码**（必填）：6 位 A 股 / 场内 ETF 代码（个股 60/68/00/30，ETF 51/56/58/15/16/18）。
- **名称**（可选）：提升妙想查询精度，可省略。
- **天数**（可选，默认 60）：拉取的日 K 线根数，上限 120。≥ 60 才能算出 MA60 与 MACD，趋势判断建议用默认值。

脚本输出 6 段数据包：**① 实时快照**（现价/涨跌幅/振幅/均价VWAP/量比/换手率/内外盘/委比/日内位置）→ **② 当日资金流**（5 档净流入 + 资金结构 + 净占比）→ **③ 近 N 日 K 线 + 趋势 + 量能**（MA5/10/20/60、均线排列、RSI/MACD/KDJ、布林、关键支撑压力、市场状态、量价关系、OBV能量潮、地量/滞涨检测）→ **④ 近 5 日资金流趋势**（5 档 + 累计）→ **⑤ 做 T 测算**（5 分钟 K 线支撑压力、日内振幅、市场状态、做 T 可行性判断；仅判定「✅ 适合」时才给出建议买卖挂单价，否则明确「❌ 不适合」及原因）→ **⑥ 抄底信号测算**（超卖/深度回撤/底背离/止跌K线形态/资金背离吸筹/靠近强支撑，聚合判定「✅ 可尝试抄底 / ⚠️ 超跌未企稳 / ❌ 无抄底信号」）。

## 分析框架（AI 在数据包之上生成报告）

严格按以下 6 段组织输出。**核心：仓位层与做 T 层是两个独立结论，必须分开下，且允许并存**（例如「中期减仓」但「日内超跌可做 T 抄底」）。

### 一、标的现在什么位置（关键结论放句首）
从「①③」提炼，用「关键结论：xxx」开头。一句话说清：现价在今日高低区间的哪个位置（①日内位置）、在近 N 日趋势里的哪个阶段（③均线排列 + 市场状态 + 区间涨跌幅）、靠近支撑还是压力（③关键位）。

### 二、今日资金与量价配合（多空方向）
从「②④」判断资金方向，从「①」判断量价：
- **主力 vs 散户方向**（②5 档 + 资金结构标签）：机构主导 / 主力偏多 / 散户主导 / 机构出货等。
- **量价配合**（①）：涨跌幅 + 量比 + 换手率 + 内外盘 + 委比，判断「放量上涨（健康）/ 缩量上涨（乏力）/ 放量下跌（出货）/ 缩量下跌（抛压减轻）」。
- **量价关系 + OBV 能量潮**（③）：`量价关系`给出「放量/缩量/平量 × 上涨/下跌/震荡」；`OBV能量潮`给出资金趋势信号——顶背离⚠️=价涨量缩出货、底背离=价跌量增吸筹、加速/持续/转向流入流出；`地量`=交投清淡变盘前兆，`滞涨`=涨幅小却放量的出货嫌疑。OBV 顶/底背离与②资金背离可交叉验证，两者同向时信号更可靠。
- **背离信号**：价跌但主力逆势净流入（吸筹）、价涨但主力净流出（出货）。
- **5 日趋势**（④）：主力是否连续净流入/流出（比单日更可靠）。

### 三、仓位决策：建仓 / 加仓 / 减仓 / 清仓 / 不动（表格）
先给**一句话结论**（五个动作选一个，及核心理由）。再用表格给依据：

| 维度 | 信号 | 偏向 |
|---|---|---|
| 趋势（③市场状态/均线排列） | 趋势上涨/震荡/趋势下跌 | 顺势加减、逆势减 |
| 资金（②④） | 主力连续流入/流出、是否背离 | 流入偏建/加、流出偏减/清 |
| 量价（①） | 放量/缩量 + 涨跌 | 放量上涨偏加、放量下跌偏清 |
| 技术位（③支撑压力/RSI/KDJ） | 靠近支撑/压力、超买/超卖 | 低位偏买、高位偏卖 |

**动作判定参考**（非机械，需综合）：
- **建仓**：无底仓 + 趋势企稳/向上 + 主力净流入 + 现价靠近支撑或刚突破。
- **加仓**：已有底仓 + 趋势向上 + 主力持续流入 + 放量突破或回踩支撑。
- **减仓**：涨幅已高（靠近压力/RSI 超买）+ 主力净流出/量价背离，落袋部分。
- **清仓**：趋势转空（跌破关键支撑/均线空头）+ 主力大幅流出 + 放量下跌。
- **不动**：震荡市方向不明、信号冲突、数据不足时默认观望。

**抄底判定（⑥，独立下结论，与「建仓」区分）**：脚本【6】已按硬门槛分级「✅ 可尝试抄底 / ⚠️ 超跌未企稳 / ❌ 无抄底信号」，AI 严格遵循脚本分级：
- 抄底 = 逆势左侧，与「建仓」的顺势逻辑相反；只在**已超跌**（⑥超卖/深度回撤）+ **至少一项主动止跌确认**（底背离/止跌K线形态/资金背离吸筹）同时满足时才提示「可尝试抄底」；「靠近强支撑」仅作加分，不算独立确认。
- 脚本判「⚠️ / ❌」时，报告中明确写「不抄底/观望」并复述原因，不给抄底价位。
- 脚本判「✅」时，用③支撑位给抄底参考区间与止损（跌破支撑即止损），并强调**轻仓、左侧、分批**，不做满仓押注。

**止损/止盈参考**单独写一行（用③支撑压力给关键位）。

### 四、是否适合做 T（结论 + 依据）
**稳健优先：默认不提示做 T。** 只有脚本【5】判定「✅ 适合」才给做 T 建议；脚本判定「❌ 不适合」时，报告中明确写「不适合做 T」并复述原因，**不再给任何做 T 挂单建议**。

脚本已按硬门槛预判，AI 严格遵循，不得在脚本判「❌」后仍建议做 T。三条硬门槛（对应脚本「❌」的 reasons）：
1. **非单边**（⑤市场状态）：趋势上涨/趋势下跌 = 单边，**不提示做 T**；窄幅震荡 = 即将变盘，**不提示**。只有「震荡」类才考虑。
2. **振幅够**（⑤日内振幅 ≥ 门槛，ETF 0.8%/个股 1.5%）：不足则价差覆盖不了成本，**不提示**。
3. **区间够**（⑤支撑/压力区间 ≥ 0.8%）：过窄无利润空间，**不提示**。

若脚本判「✅ 适合」，用一句话说明「为什么适合」（震荡 + 振幅/区间充足），再进入「五」给挂单。若「❌」，说明等什么条件能转适合（如：等振幅放大 / 等单边结束回到箱体）。

### 五、做 T 挂单（仅在脚本「✅ 适合」时给出；「❌」时本段整体省略）
以「⑤」的建议买卖挂单价为基准微调，给出表格：

| 方向 | 挂单价 | 逻辑 |
|---|---|---|
| 买单（低吸） | ⑤买单价 | 支撑上方留缓冲，避免挂太低不成交 |
| 卖单（高抛） | ⑤卖单价 | 压力下方留缓冲，避免挂太高不成交 |
| 止损/破位 | 跌破支撑 xx | 做 T 底仓保护 |

**正 T / 反 T 说明**：有底仓做「正 T」（先买后卖）；仅想日内高抛低吸做「反 T」（先卖后买）需已有持仓。无持仓只能做日内「先买后卖」的正 T，且当天无法平仓（A 股 T+1），需提示风险。
**成本校验**单独一行：价差须 ≫ 双边佣金 + 印花税（卖出千 0.5），否则做 T 白忙。

### 六、免责声明（每次必带）
固定加一句：以上是基于公开行情/资金流/技术指标的量化分析，不构成投资建议；盘中数据实时变动，做 T 是高风险短线操作，请控制仓位、独立决策。

## 注意事项

- **数据源**：实时快照（新浪+腾讯）、当日资金流（东财分钟级 fflow）、日 K 线/5 分钟 K 线（新浪，AKShare 兜底）、近 5 日资金流（妙想）。**核心功能不依赖 `MX_APIKEY`**，无 key 也能跑（仅【4】近 5 日资金流趋势会跳过）。
- **仓位决策与做 T 是两个层次**：仓位决策看日线趋势 + 资金趋势；做 T 看 5 分钟级别震荡。两者可能矛盾（中期看空但日内超跌可做 T），必须分两段写清楚，不能混成一句。
- **A 股 T+1 约束**：普通 A 股当日买入次日才能卖，做 T 只能基于「已有底仓」（先卖后买）或「买入后持有至次日」。ETF 部分品种支持 T+0，需标注品种差异。
- **ETF 资金流口径**：场内 ETF 的「资金流」是二级市场成交拆单口径，不等于基金申赎净额，解读时结合指数/板块走势。
- **时效**：数据为盘中实时（仅交易时段有效），收盘后运行得到的是当日收盘快照，做 T 结论失效，应提示「已收盘，仅供复盘」。
- **不臆造**：脚本没查到的数据（财务、消息面等）不要编造；需要消息面可叠加 `/stock-analysis` 或 `/fund-flow`。
- **抄底是左侧逆势、高风险**：即使脚本判「✅」，也只是「超跌 + 止跌确认」的概率信号，仍可能继续下跌（接飞刀）；必须设好止损、轻仓分批，宁可错过不可满仓。
- **预测是概率判断，不是保证**：始终给关键位与触发条件，避免「必涨/必跌」「稳赚」的绝对表述。
